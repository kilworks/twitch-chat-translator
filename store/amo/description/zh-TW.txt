Twitch Chat Translator 是一款免費的 Twitch 聊天室翻譯擴充功能。用你自己的語言閱讀任何實況的聊天室，並直接在聊天室裡用頻道的語言回覆。

正在看土耳其語、西班牙語、俄語或阿拉伯語的實況，卻看不懂聊天室？安裝後打開實況，每則訊息一出現，正下方就會顯示它的翻譯。不需要帳號，不需要 API 金鑰，什麼都不用設定。

使用方式

1. 打開任何 Twitch 實況。聊天室上方的紫色列表示翻譯功能已啟用。
2. 每則新訊息下方都會顯示翻譯，語言為你瀏覽器的語言。
3. 用你自己的語言輸入回覆。預覽會以頻道的語言顯示：按 Tab 或點一下預覽，然後送出。

頻道的語言就是實況主在 Twitch 上設定的語言，兩種語言都可以在設定中更改。即時聊天室、彈出視窗、嵌入、管理員檢視和實況管理員都能用，VOD 和剪輯重播也行，有沒有 7TV、BTTV 和 FFZ 都可以。在背景分頁時會自動暫停（這是一項設定，預設開啟）。

功能一覽

• 43 種語言，包含由右至左書寫的語言（阿拉伯語、希伯來語、波斯語），並區分各地區變體（巴西葡萄牙語、繁體中文）。
• 開箱即用，透過 Google Translate 免費翻譯，不需要金鑰，也不需要帳號。
• 使用你自己的 DeepL API 金鑰，歐洲語言的翻譯更好。DeepL 會收到最近的聊天內容作為上下文，讓用詞貼合對話。
• 自動備援：一個引擎失敗時，由 MyMemory 或 Lingva 接手。順序由你決定。
• 四種顯示方式：在訊息下方、與訊息同一行、取代訊息，或只在滑鼠移上去時顯示。懸停模式在你指向某則訊息之前不會翻譯任何內容，在聊天室刷得很快時能節省你的額度。
• 過濾：略過機器人、封鎖使用者或頻道、隱藏含有你指定字詞的訊息（對付 !command 洗版很好用），或只翻譯你想要的語言。
• 頻道的 7TV、BTTV 和 FFZ 表情集裡的表情名稱絕不會被翻譯，就算你沒有執行那些擴充功能也一樣。@提及和連結會在送出前先分開處理，只有 emoji 或笑聲的訊息會被略過，所以不會浪費額度去翻譯「kkkkkk」。
• 被管理員刪除的訊息，以及被禁言或封鎖而消失的訊息，翻譯也會一併消失。
• 照你的喜好調整：文字大小、行距、字型、強調色、深色或淺色聊天室（預設跟著 Twitch 本身的）、依頻道記住的閱讀語言、鍵盤快速鍵。
• 介面同樣支援這 43 種語言，包含由右至左書寫的語言，可從顯示各語言旗幟的選單中挑選。

哪些內容會離開你的瀏覽器

聊天文字只會傳給你選擇的翻譯引擎，輸入預覽開啟時你的草稿也一樣。使用 Google、MyMemory 或 Lingva 時，傳出的只有每則訊息的文字，沒有其他：不含頻道，也不含發言者。使用 DeepL 時，最近幾行聊天內容會作為上下文一併傳出，並附上發言者的名稱，讓翻譯貼合對話。上面權限中提到的「網站內容」指的就是這些。沒有帳號，也沒有我的伺服器。除了你選擇的引擎，這個擴充功能還會與以下對象連線：Twitch，用來查詢頻道的語言和 id；7TV、BetterTTV 和 FrankerFaceZ，用來查詢頻道的表情名稱，這只會讓它們知道該頻道的 id，沒有其他；以及在手動安裝的版本中，GitHub 的發行頁面（用來在有新版本時通知你），該請求不會帶任何內容。若你勾選選用的「技術與互動資料」，也會每天向 Google Analytics 傳送一次匿名計數：使用的引擎、錯誤與速度，絕不包含你的訊息、名稱或頻道。
