Twitch Chat Translator는 Twitch를 위한 무료 실시간 채팅 번역 확장 프로그램입니다. 어떤 방송의 채팅이든 내 언어로 읽고, 채널의 언어로 답장하세요. 모두 채팅 안에서 바로 이루어집니다.

터키어, 스페인어, 러시아어, 아랍어 방송을 보는데 채팅을 따라가지 못하나요? 설치하고 방송을 열면, 메시지가 도착하는 대로 바로 아래에 번역이 붙습니다. 계정도, API 키도, 설정할 것도 없습니다.

작동 방식

1. 아무 Twitch 방송이나 여세요. 채팅 상단의 보라색 막대가 번역기가 켜져 있음을 알려 줍니다.
2. 새 메시지마다 그 아래에 브라우저 언어로 된 번역이 붙습니다.
3. 내 언어로 답장을 입력하세요. 미리보기가 채널의 언어로 보여 줍니다. Tab을 누르거나 미리보기를 클릭한 뒤 보내면 됩니다.

채널의 언어는 스트리머가 Twitch에서 설정한 언어이며, 두 언어 모두 설정에서 바꿀 수 있습니다. 라이브 채팅, 팝아웃, 임베드, 관리자 보기, 방송 관리자는 물론 VOD와 클립 다시보기에서도 동작하며, 7TV, BTTV, FFZ가 있어도 없어도 됩니다. 백그라운드 탭에서는 스스로 멈춥니다(설정이며, 기본으로 켜져 있습니다).

제공 기능

• 43개 언어. 오른쪽에서 왼쪽으로 쓰는 언어(아랍어, 히브리어, 페르시아어)를 포함하고, 지역 변형(브라질 포르투갈어, 번체 중국어)도 따로 구분합니다.
• Google 번역으로 처음부터 무료, 키도 계정도 필요 없습니다.
• 내 DeepL API 키를 직접 추가하면 유럽 언어의 품질이 올라갑니다. DeepL에는 최근 채팅 몇 줄이 문맥으로 전달되어 표현이 대화에 맞습니다.
• 자동 대체: 한 엔진이 실패하면 MyMemory나 Lingva가 이어받습니다. 순서는 직접 정합니다.
• 네 가지 표시 방식: 메시지 아래, 같은 줄, 메시지 대신, 또는 마우스를 올렸을 때만. 마우스 오버 모드는 메시지를 가리키기 전까지 아무것도 번역하지 않아, 빠른 채팅에서 할당량을 아껴 줍니다.
• 필터: 봇 건너뛰기, 사용자나 채널 차단, 직접 고른 단어가 들어간 줄 숨기기(!명령어 도배에 유용), 원하는 언어만 번역하기.
• 채널의 7TV, BTTV, FFZ 세트에 있는 이모트 이름은 그 확장 프로그램을 쓰지 않아도 절대 번역하지 않습니다. @멘션과 링크는 전송 전에 따로 빼 두고, 이모지나 웃음뿐인 줄은 건너뛰므로 "kkkkkk"를 번역하느라 사용량을 쓰지 않습니다.
• 관리자가 삭제한 메시지, 타임아웃이나 차단으로 사라진 메시지는 번역도 함께 사라집니다.
• 내 취향대로: 글자 크기, 줄 간격, 글꼴, 강조색, 어두운 또는 밝은 채팅(기본으로 Twitch의 것을 따릅니다), 채널마다 기억되는 읽기 언어, 단축키.
• 인터페이스도 같은 43개 언어로 제공하며, 오른쪽에서 왼쪽으로 쓰는 언어도 포함됩니다. 언어별 국기가 표시되는 메뉴에서 고를 수 있습니다.

브라우저에서 무엇이 나가는가

채팅 문장은 선택한 번역 엔진으로만 가고, 작성 미리보기가 켜져 있을 때의 초안도 마찬가지입니다. Google, MyMemory, Lingva에서는 각 메시지의 문장만 가고 그 밖에는 아무것도 가지 않습니다. 채널도, 누가 말했는지도 가지 않습니다. DeepL에서는 번역이 대화에 맞도록 최근 채팅 몇 줄이 쓴 사람의 이름과 함께 문맥으로 전달됩니다. 위 권한의 “웹사이트 콘텐츠” 항목이 가리키는 것이 이것입니다. 계정도, 제 서버도 없습니다. 선택한 엔진 외에 확장 프로그램이 통신하는 곳은 다음과 같습니다. Twitch(채널의 언어와 id를 묻기 위해), 7TV, BetterTTV, FrankerFaceZ(채널의 이모트 이름을 묻기 위해, 이때 그들에게 알려지는 것은 채널의 id뿐입니다), 그리고 직접 설치한 버전에서는 새 버전이 있는지 알리기 위한 GitHub 릴리스 페이지이며, 이 요청에는 아무것도 실어 보내지 않습니다. 선택 항목인 “기술 및 상호작용 데이터”에 체크한 경우에만 사용한 엔진, 오류, 속도의 익명 집계를 하루 한 번 Google Analytics에도 보내며, 메시지, 이름, 채널은 절대 보내지 않습니다.
