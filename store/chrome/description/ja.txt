Twitch Chat Translator は、Twitch 用の無料ライブチャット翻訳拡張機能です。どの配信のチャットも自分の言語で読み、チャンネルの言語で返信できます。すべてチャット欄の中で完結します。

トルコ語、スペイン語、ロシア語、アラビア語の配信を見ていて、チャットについていけないことはありませんか？インストールして配信を開くだけで、届いたメッセージの真下にその場で翻訳が付きます。アカウントも API キーも要らず、設定することもありません。

使い方

1. Twitch の配信をどれでも開きます。チャット上部の紫のバーが、翻訳機能がオンであることを示します。
2. 新しいメッセージごとに、その下にブラウザの言語での翻訳が付きます。
3. 自分の言語で返信を打ちます。チャンネルの言語でのプレビューが表示されるので、Tab を押すかクリックしてから送信します。

チャンネルの言語は配信者が Twitch で設定した言語で、どちらの言語も設定で変更できます。ライブチャット、ポップアウト、埋め込み、モデレータービュー、配信マネージャー、さらに VOD とクリップのリプレイで動き、7TV、BTTV、FFZ があってもなくても使えます。バックグラウンドのタブでは自動で一時停止します（設定で、初期状態はオン）。

主な機能

• 43言語に対応。右から左に書く言語（アラビア語、ヘブライ語、ペルシア語）も含み、地域変種（ブラジルポルトガル語、繁体字中国語）も区別して扱います。
• Google 翻訳で、インストールしてすぐ無料で使えます。キーもアカウントも要りません。
• 自分の DeepL API キーを使うと、ヨーロッパ言語の品質が上がります。DeepL には直近のチャットの発言も文脈として渡すので、言い回しが会話に沿います。
• Chrome と Edge 138 以降では、パソコンが対応していれば端末内で翻訳できます。オフラインで、上限なしで、チャットが端末から出ることはありません。
• 自動フォールバック：あるエンジンが失敗すると、MyMemory か Lingva が引き継ぎます。順番は自分で決められます。
• 四つの表示スタイル：メッセージの下、同じ行、メッセージと置き換え、またはカーソルを乗せたときだけ。カーソル表示モードはメッセージを指すまで何も翻訳しないので、速いチャットでも使用量を節約できます。
• フィルター：ボットの発言を除外する、ユーザーやチャンネルをミュートする、選んだ言葉を含む行を隠す（!コマンドの連投対策に便利）、翻訳したい言語だけを翻訳する。
• チャンネルの 7TV、BTTV、FFZ のエモート名は、それらの拡張機能を使っていなくても翻訳しません。@メンションとリンクは送信前に分けておき、絵文字や笑いだけの行は飛ばすので、「wwwww」の翻訳に何も費やしません。
• モデレーターが削除したメッセージや、タイムアウトやバンで消えたメッセージは、翻訳も消えます。
• 自分好みに：文字サイズ、行間、書体、アクセントカラー、ダークまたはライトのチャット（初期設定では Twitch に合わせます）、チャンネルごとに覚える読む言語、キーボードショートカット。
• インターフェースも同じ43言語に対応。右から左へ書く言語も含み、各言語の国旗が並ぶメニューから選べます。

プライバシー

アカウントも私のサーバーもありません。アクセス解析は行いません。ただし同意した場合に限り、使ったエンジン、エラー、速度の匿名集計を1日1回だけ送ります。メッセージ、名前、チャンネルは一切送りません。チャットの文章は、あなたが選んだ翻訳エンジンにだけ送られ、入力プレビューがオンのときの下書きも同じです。Google、MyMemory、Lingva の場合は、本文だけで、ほかには何も送りません。DeepL の場合は、翻訳が会話に沿うよう、直近の数行のチャットを、書いた人の名前と一緒に文脈として送ります。見ているチャンネルが翻訳エンジンに送られることはなく、端末内翻訳ならチャットの文章はパソコンから出ません。チャンネルが名指しされるのは一か所だけです。拡張機能が Twitch にチャンネルの言語を問い合わせ、7TV、BetterTTV、FrankerFaceZ にエモート名を問い合わせます。これで先方に伝わるのはチャンネルの id だけです。

権限をわかりやすく言うと、設定と翻訳キャッシュのための保存領域、チャットに翻訳を表示するための twitch.tv と、dashboard.twitch.tv の配信マネージャーへのアクセス、エモート名を翻訳しないための Twitch の言語照会と 7TV、BetterTTV、FrankerFaceZ のエモート一覧へのアクセス、呼び出しうるエンジン（Google、DeepL、MyMemory、Lingva）へのアクセス、見ている間に翻訳機能を待機させておくためのタイマー、そしてインストール時や更新時に、すでに開いている Twitch のタブへ自分のスクリプトを読み込み直す権限です。これにより、ページを再読み込みしなくても翻訳が続きます。さらに、翻訳を挿入するときにメッセージ欄へ書き込むため、Twitch のページで自前の関数を一つ実行する権限もあります。手動でインストールした場合は、新しいバージョンがあることを知らせるために GitHub のリリースページも読みますが、その通信では何も送りません。
