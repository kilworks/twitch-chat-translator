Twitch Chat Translator 是一款免费的 Twitch 直播聊天翻译扩展。用你自己的语言阅读任何直播的聊天，并直接在聊天框里用频道的语言回复。

在看土耳其语、西班牙语、俄语或阿拉伯语的直播，却看不懂聊天？安装后打开直播，每条消息一到，正下方就会出现它的译文。无需账号，无需 API 密钥，什么都不用设置。

使用方法

1. 打开任意 Twitch 直播。聊天区顶部的紫色条表示翻译器已开启。
2. 每条新消息下方都会显示译文，语言为你浏览器的语言。
3. 用你自己的语言输入回复。预览会以频道的语言显示它：按 Tab 或点击预览，然后发送。

频道的语言就是主播在 Twitch 上设置的语言，两种语言都可以在设置里更改。实时聊天、弹出窗口、嵌入、管理员视图和直播管理器都能用，VOD 回放和剪辑重放也行，有没有 7TV、BTTV 和 FFZ 都可以。后台标签页会自行暂停（这是一项设置，默认开启）。

功能一览

• 43 种语言，包含从右向左书写的语言（阿拉伯语、希伯来语、波斯语），并区分地区变体（巴西葡萄牙语、繁体中文）。
• 开箱即用，使用 Google 翻译免费翻译，不需要密钥，也不需要账号。
• 用你自己的 DeepL API 密钥获得更好的欧洲语言译文。DeepL 会收到最近的聊天内容作为上下文，因此措辞贴合对话。
• 在 Chrome 和 Edge 138 及以上版本中，如果你的电脑支持，可在设备端翻译：离线、无上限，聊天内容不会离开你的机器。
• 自动备用：一个引擎失败时，由 MyMemory 或 Lingva 接手。顺序由你决定。
• 四种显示方式：在原文下方、与原文同一行、替换原文，或仅在鼠标悬停时显示。悬停模式在你指向某条消息之前不翻译任何内容，在快速滚动的聊天中能节省你的额度。
• 过滤：跳过机器人，屏蔽用户或频道，隐藏包含你所选词语的行（对付 !命令 刷屏很方便），或只翻译你想要的语言。
• 频道的 7TV、BTTV 和 FFZ 表情集里的表情名称绝不会被翻译，即使你没有运行这些扩展。@提及和链接在发送前就被单独分开，只有 emoji 或笑声的行会被跳过，不会浪费额度去翻译「kkkkkk」。
• 被管理员删除的消息，以及被超时或封禁而消失的消息，译文也会一并消失。
• 按你的喜好调整：文字大小、行距、字体、强调色、深色或浅色聊天（默认跟随 Twitch 自己的）、按频道记住的阅读语言、键盘快捷键。
• 界面同样支持这 43 种语言，包括从右向左书写的语言，可从显示各语言旗帜的菜单中选择。

隐私

没有账号，也没有我的服务器。除非你同意，否则没有分析统计；同意后每天只发送一次匿名计数：使用的引擎、错误和速度，绝不包含你的消息、名称或频道。聊天文本只发送给你选择的翻译引擎，输入预览开启时你的草稿也一样。使用 Google、MyMemory 或 Lingva 时，发送的只有文本，别无其他。使用 DeepL 时，最近几行聊天会作为上下文一并发送，附带发言者的名字，让译文贴合对话。你观看的频道从不发送给翻译引擎；使用设备端翻译时，聊天文本不会离开你的电脑。频道只在一个地方被提到：扩展会向 Twitch 查询它的语言，并向 7TV、BetterTTV 和 FrankerFaceZ 查询它的表情名称，这只会让它们知道该频道的 id，别无其他。

权限的通俗说明：存储权限，用于保存你的设置和翻译缓存；访问 twitch.tv 以及 dashboard.twitch.tv 上的直播管理器，用于在聊天中显示译文；访问 Twitch 的语言查询以及 7TV、BetterTTV 和 FrankerFaceZ 的表情列表，这样表情名称就不会被翻译；访问它可能调用的引擎（Google、DeepL、MyMemory 和 Lingva）；一个唤醒定时器，让翻译器在你观看时保持就绪；在安装或更新时把自己的脚本重新载入已打开的 Twitch 标签页的权限，这样无需刷新就能继续翻译；以及在 Twitch 页面中运行它自己的一个函数，在你插入译文时把它写入消息框。手动安装的版本还会读取 GitHub 的发布页面来告知你有新版本，该请求不携带任何内容。
