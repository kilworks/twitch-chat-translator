Twitch Chat Translator คือส่วนขยายแปลแชทสดฟรีสำหรับ Twitch อ่านแชทของสตรีมไหนก็ได้เป็นภาษาของคุณเอง แล้วตอบกลับเป็นภาษาของช่องได้ในแชทเลย

ดูสตรีมภาษาตุรกี สเปน รัสเซีย หรืออาหรับ แล้วตามแชทไม่ทัน? แค่ติดตั้งแล้วเปิดสตรีม ทุกข้อความจะมีคำแปลโผล่ใต้ข้อความทันทีที่เข้ามา ไม่ต้องมีบัญชี ไม่ต้องใช้ API key ไม่ต้องตั้งค่าอะไรเลย

ใช้งานอย่างไร

1. เปิดสตรีม Twitch ไหนก็ได้ แถบสีม่วงด้านบนของแชทแสดงว่าตัวแปลทำงานอยู่
2. ทุกข้อความใหม่จะมีคำแปลอยู่ด้านล่าง เป็นภาษาของเบราว์เซอร์คุณ
3. พิมพ์ตอบเป็นภาษาของคุณ ระบบจะแสดงตัวอย่างเป็นภาษาของช่อง กด Tab หรือคลิกที่ตัวอย่าง แล้วส่งได้เลย

ภาษาของช่องคือภาษาที่สตรีมเมอร์ตั้งไว้บน Twitch และเปลี่ยนได้ทั้งสองภาษาในการตั้งค่า ใช้ได้กับแชทสด ป็อปเอาต์ เอ็มเบด มุมมองมอดเดอเรเตอร์ และสตรีมแมเนเจอร์ รวมถึงการเล่นย้อนหลังของ VOD และคลิป ไม่ว่าจะมี 7TV, BTTV และ FFZ หรือไม่ และหยุดทำงานเองเมื่ออยู่ในแท็บเบื้องหลัง (เป็นการตั้งค่า เปิดไว้เป็นค่าเริ่มต้น)

สิ่งที่คุณจะได้

• 43 ภาษา รวมภาษาที่เขียนจากขวาไปซ้าย (อาหรับ ฮีบรู เปอร์เซีย) และแยกสำเนียงตามภูมิภาคไว้ต่างหาก (โปรตุเกสแบบบราซิล จีนตัวเต็ม)
• ใช้ฟรีได้ทันทีด้วย Google Translate ไม่ต้องมี key ไม่ต้องมีบัญชี
• ภาษายุโรปแปลได้ดีขึ้นเมื่อใช้ DeepL API key ของคุณเอง DeepL จะได้รับบรรทัดแชทล่าสุดเป็นบริบท ถ้อยคำจึงเข้ากับบทสนทนา
• แปลบนเครื่องใน Chrome และ Edge 138+ เมื่อคอมพิวเตอร์รองรับ ใช้ออฟไลน์ได้ ไม่จำกัด และแชทไม่ออกจากเครื่องของคุณ
• สำรองอัตโนมัติ: เมื่อเอนจินหนึ่งใช้ไม่ได้ MyMemory หรือ Lingva จะรับช่วงต่อ คุณเลือกลำดับได้เอง
• สี่รูปแบบการแสดงผล: ใต้ข้อความ บรรทัดเดียวกัน แทนที่ข้อความเดิม หรือเฉพาะตอนที่เอาเมาส์ไปชี้ โหมดชี้เมาส์จะไม่แปลอะไรเลยจนกว่าคุณจะชี้ที่ข้อความ ช่วยประหยัดโควตาในแชทที่วิ่งเร็ว
• ตัวกรอง: ข้ามบอต ปิดเสียงผู้ใช้หรือช่อง ซ่อนบรรทัดที่มีคำที่คุณเลือก (ช่วยรับมือสแปม !command) หรือแปลเฉพาะภาษาที่คุณต้องการ
• ชื่ออีโมตจากชุด 7TV, BTTV และ FFZ ของช่องจะไม่ถูกแปลเลย แม้คุณไม่ได้ใช้ส่วนขยายเหล่านั้น @mention และลิงก์ถูกแยกไว้ก่อนส่งอะไรออกไป และบรรทัดที่มีแต่อีโมจิหรือเสียงหัวเราะจะถูกข้าม จึงไม่เสียโควตาไปกับการแปล "kkkkkk"
• ข้อความที่มอดเดอเรเตอร์ลบ หรือที่ถูกไทม์เอาต์หรือแบนเอาออก ก็เสียคำแปลไปด้วย
• ปรับให้เป็นของคุณ: ขนาดตัวอักษร ระยะห่างบรรทัด แบบอักษร สีเน้น แชทโหมดมืดหรือสว่าง (ตามของ Twitch เองเป็นค่าเริ่มต้น) ภาษาที่อ่านซึ่งจำแยกตามแต่ละช่อง และคีย์ลัด
• หน้าตาส่วนขยายมีครบทั้ง 43 ภาษาเดียวกัน รวมภาษาที่เขียนจากขวาไปซ้าย เลือกได้จากเมนูที่แสดงธงของแต่ละภาษา

ความเป็นส่วนตัว

ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ของผม และไม่มีระบบวิเคราะห์ เว้นแต่คุณยินยอมให้นับแบบไม่ระบุตัวตนวันละครั้งเรื่องเอนจินที่ใช้ ข้อผิดพลาด และความเร็ว ไม่มีข้อความ ชื่อ หรือช่องของคุณเด็ดขาด ข้อความแชท รวมถึงร่างของคุณขณะที่เปิดตัวอย่างข้อความที่พิมพ์ จะไปที่เอนจินแปลที่คุณเลือกเท่านั้น หากใช้ Google, MyMemory หรือ Lingva จะส่งเฉพาะข้อความของแต่ละข้อความและไม่มีอย่างอื่น หากใช้ DeepL จะส่งบรรทัดแชทล่าสุดไม่กี่บรรทัดไปเป็นบริบทพร้อมชื่อของคนที่เขียน เพื่อให้คำแปลเข้ากับบทสนทนา ช่องที่คุณดูจะไม่ถูกส่งไปที่เอนจินเลย และถ้าแปลบนเครื่อง จะไม่มีข้อความแชทออกจากคอมพิวเตอร์คุณ ช่องถูกระบุชื่อที่เดียวเท่านั้น: ส่วนขยายถาม Twitch เรื่องภาษาของช่อง และถาม 7TV, BetterTTV และ FrankerFaceZ เรื่องชื่ออีโมตของช่อง ซึ่งทำให้พวกเขารู้ id ของช่องและไม่มีอะไรอื่น

สิทธิ์ที่ขอ พูดให้เข้าใจง่าย: storage สำหรับการตั้งค่าและแคชคำแปล การเข้าถึง twitch.tv และสตรีมแมเนเจอร์บน dashboard.twitch.tv เพื่อแสดงคำแปลในแชท การเข้าถึงการค้นหาภาษาของ Twitch และรายชื่ออีโมตของ 7TV, BetterTTV และ FrankerFaceZ เพื่อไม่ให้ชื่ออีโมตถูกแปล การเข้าถึงเอนจินที่เรียกใช้ได้ (Google, DeepL, MyMemory และ Lingva) ตัวตั้งเวลาปลุกเพื่อให้ตัวแปลพร้อมอยู่ขณะที่คุณดู และสิทธิ์โหลดสคริปต์ของตัวเองซ้ำในแท็บ Twitch ที่เปิดอยู่แล้วตอนติดตั้งหรืออัปเดต เพื่อให้แปลต่อได้โดยไม่ต้องรีเฟรช และสิทธิ์รันฟังก์ชันของตัวเองหนึ่งตัวในหน้า Twitch เพื่อเขียนคำแปลลงในช่องพิมพ์ข้อความเมื่อคุณใส่คำแปล ในเวอร์ชันที่ติดตั้งเองยังอ่านหน้า GitHub releases เพื่อแจ้งคุณเมื่อมีเวอร์ชันใหม่ โดยไม่ส่งอะไรไปกับคำขอนั้น
