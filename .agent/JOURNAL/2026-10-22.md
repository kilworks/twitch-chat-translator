## Probes that were wrong, and what they taught

- First matrix run: 4 parallel cells of the same config shared one Chromium profile and died on
  the profile lock. One profile per cell now.
- Embed with an `http` host page found nothing on 6 channels: Twitch embeds need an https
  parent. Host page now served by route on https.
- Channels drawn at random were mostly quiet (adds 0 or 1): `heat.mjs` ranks them first.
- Inventory parser took key names (`shiftKey`, `ctrlKey`) for compose outcomes (11 instead of
  7) and counted `.test.ts` files as catalogues. Both fixed, re-run.
- Language tags: the probe read tag links from the whole page, sidebar included; 2 of 4
  disagreements were "English" tags on FR and RU channels. Tags dropped as a source.
- a11y contrast: 1.37:1 on translations was the probe treating a 6% green tint as opaque; the
  screenshot and a composited computation give about 9.9:1. Retry buttons at 1:1 are opacity 0
  until hover. Both recorded as probe errors in RECON/a11y/measure.json.
- Hidden tab: four methods (second tab in front, CDP minimise headless, CDP minimise headed,
  headed without Playwright's backgrounding flags) and the chrome-devtools browser all kept
  `visibilityState` at `visible`. The probe now fails when the page never hides. Left to K06.
- Theater proof: the first witness (top `nav` height) did not change; the video geometry did
  (1020x574 to 1260x1000). A screenshot proof was dropped because cropping out channel names
  removed it.
- Redaction: `save()` only redacted the probe's own channel; the SPA cell navigates to a second
  one, which leaked into 8 `spa/dom.html`. `save()` now redacts all 40 drawn logins; existing
  files re-sanitised (15 changed), screenshots cropped to the chat column (57 files).
- The Edit tool turned the unicode escapes for the en and em dash into literal characters inside lib.mjs; replaced by
  `String.fromCharCode`.
- `git mv -k` on untracked files returns 0 and moves nothing.
- On Windows `.agent/recon` and `.agent/RECON` are one directory: probes now live in
  `.agent/probes`.
