# Twitch Chat Translator

Читайте чат будь-якого стріму на Twitch своєю мовою й відповідайте мовою каналу.<br>

## Як це працює

1. Установіть розширення й відкрийте будь-який стрім на Twitch. Фіолетова смуга вгорі чату показує, що воно
   ввімкнене.
2. Кожне повідомлення отримує переклад одразу під собою, щойно надходить, мовою вашого браузера. Так само на
   прямих ефірах, записах VOD і кліпах.
3. Напишіть відповідь своєю мовою. Попередній перегляд над полем введення покаже її мовою каналу: натисніть Tab
   або клацніть по ньому, і цей варіант замінить набраний текст.

Мова каналу це та, яку стример указав на Twitch, тож налаштовувати нічого не треба. Обидві мови змінюються в
налаштуваннях, а мову читання можна запам'ятовувати окремо для кожного каналу.

Якщо ви користуєтеся ще й 7TV або BTTV, вони використовують Tab, щоб дописати емоут. Тоді Tab спершу дописує емоут, а переклад вставляє, лише якщо дописувати не було чого. Ctrl/Cmd+Enter і клацання вставляють його завжди.

## Що ви отримуєте

- **43 мови**, зокрема з письмом справа наліво (арабська, іврит, перська); регіональні варіанти не
  змішуються (бразильська й європейська португальська, спрощена й традиційна китайська, кантонська)
- **Скрізь, де є чат**: прямий чат, спливний чат, вбудований чат, режим модератора, менеджер трансляції,
  відтворення VOD і кліпів, на www.twitch.tv, m.twitch.tv і dashboard.twitch.tv, з 7TV, BTTV і FFZ або без них
- **Розширення розмовляє ними теж**: налаштування, спливне вікно й панель чату всіма 43 мовами, вибір із меню
  з прапорами
- **Безкоштовно одразу** з Google Translate. Додайте свій безкоштовний ключ DeepL для кращого перекладу
  європейськими мовами; MyMemory і Lingva підхоплюють, коли якийсь рушій відмовляє
- **Переклад на пристрої** в Chrome і Edge, де браузер його пропонує: без мережі, без квоти, а текст
  ніколи не залишає ваш комп'ютер
- **Фільтри**: пропускати ботів, глушити користувачів або канали, ховати рядки з певним словом,
  перекладати лише вибрані вами мови
- **Створено для швидких чатів**: назви емоутів із наборів каналу в 7TV, BTTV і FFZ ніколи не перекладаються, навіть
  якщо цих розширень у вас немає, посилання й @згадки відкладаються вбік до того, як щось буде надіслано, глосарій
  для імен, які рушії перекручують, кеш перекладів
- **Чотири стилі показу**: під повідомленням, у тому самому рядку, замість нього або лише при наведенні
- **Пауза для одного каналу** просто з панелі чату, решта працює далі. Зміна каналу чи оновлення
  розширення не зупиняє переклад у відкритих вкладках, перезавантажувати не треба
- **З урахуванням модерації**: повідомлення, видалене модератором, а також через тайм-аут чи бан, теж втрачає свій переклад
- **Виглядає як Twitch**: фіолетовий, і йде за власною темною або світлою темою чату, доки ви не виберете свою
- Chrome, Brave, Edge і Firefox

## Встановлення

Завантажте zip для свого браузера зі сторінки [Releases](https://github.com/kilworks/twitch-chat-translator/releases/latest) і розпакуйте його.

- Chrome, Brave, Edge (`…-chromium.zip`): відкрийте `chrome://extensions`, увімкніть режим розробника, натисніть Load unpacked і виберіть папку.
- Firefox 121+ (`…-firefox.zip`): відкрийте `about:debugging#/runtime/this-firefox`, натисніть Load Temporary Add-on і виберіть `manifest.json`.
  Firefox забуває тимчасове доповнення після перезапуску.

Копія, встановлена так, сама не оновлюється: на її значку з'являється позначка, коли є новіша версія,
а спливне вікно веде до останнього релізу.

## Рушії перекладу

Чотири сервіси, з'єднані в ланцюжок: коли один відмовляє, наступний підхоплює. Порядок задаєте ви.

| Сервіс | Ключ | Примітка |
|---|---|---|
| Google | немає | типовий, працює одразу |
| DeepL | безкоштовний | найкращий для європейських мов, [безкоштовний ключ](https://www.deepl.com/pro-api) на 1 мільйон символів на місяць |
| MyMemory | немає | запасний |
| Lingva | немає | запасний, на публічному сервері, якщо не вкажете свій |

Вбудованому перекладачу Chromium не потрібні ні мережа, ні квота. Chrome і Edge 138 та новіші можуть його
запропонувати, хоча не кожна копія його має, а для кожної пари мов модель потрібно завантажити один раз, одним
клацанням із панелі. У Firefox його немає. Де його бракує, хмарний ланцюжок підхоплює, і нічого не ламається.

## Налаштування

Клацніть шестірню на панелі чату або натисніть правою кнопкою на значок розширення й виберіть «Налаштування».

- **Сервіси**: порядок рушіїв, ваш ключ DeepL і режим: спершу на пристрої, спершу хмара або лише на пристрої
- **Вигляд**: мова перекладу, стиль показу, оригінальний текст і значок мови, розмір тексту, міжрядковий інтервал,
  шрифт, колір акценту, тема чату, попередній перегляд під час введення і що відбувається після клацання по ньому
- **Фільтри**: боти, користувачі, канали, ключові слова, мови оригіналу та глосарій замін
- **Додатково**: розмір і строк життя кешу, одночасні запити, ліміт запитів на канал, резервна копія та відновлення
- **Активність**: перекладені повідомлення, влучання в кеш, кожна мова, побачена в чаті, і чому кожен з останніх 50
  рядків було перекладено або залишено
- **Клавіатура**: Alt+Shift+T вмикає або вимикає переклад чату (Alt+T це режим театру Twitch), Alt+W попередній
  перегляд під час введення. Обидві комбінації можна змінити в сполученнях клавіш розширень вашого браузера
- Кнопка мови на панелі дій чату, під полем введення повідомлення: одне клацання відкриває список мов, якими
  ви пишете, набір тексту його фільтрує. Кнопка вгорі чату задає мову, якою ви читаєте

## Конфіденційність

Ні облікового запису, ні мого сервера, ні аналітики, якщо ви не ввімкнете щоденний анонімний підрахунок, який надсилається в Google Analytics (використані механізми, помилки, швидкість, ніколи не ваші повідомлення, імена чи канали). Повідомлення чату і ваша чернетка, поки ввімкнено попередній перегляд, йдуть лише до обраного вами сервісу перекладу й
більше нікуди, а в режимі перекладу на пристрої навіть туди ні. Щоб дізнатися мову каналу, воно запитує в Twitch мову трансляції та id каналу, а щоб назви емоутів не потрапляли в переклади, запитує в 7TV, BetterTTV і FrankerFaceZ назви емоутів каналу, і це повідомляє їм id цього каналу й нічого більше. Копія з магазину не робить жодних інших запитів.
Копія, встановлена вручну, питає GitHub про тег останньої версії щонайбільше раз на шість годин, щоб знати,
чи показувати позначку оновлення. [Докладніше](PRIVACY.md)

## Поширені запитання

**Повідомлення не перекладаються.**
Відкрийте вкладку «Активність» у налаштуваннях і натисніть «Показати рішення»: вона покаже останні 50 рядків
і чому кожен із них було перекладено або залишено. Більшість пропущених рядків пропущено навмисно: той самий
користувач повторюється, рядки закороткі, лише емодзі чи сміх, або вже мовою читання. Якщо вкладка взагалі порожня, розширення не бачить чату: будь ласка,
створіть issue.

**Фіолетова смуга зникла.**
Оновіть сторінку. Якщо повториться, створіть [issue](https://github.com/kilworks/twitch-chat-translator/issues)
з назвою каналу й тим, що ви робили перед цим.

**Як отримати кращий переклад?**
Додайте безкоштовний ключ DeepL у налаштуваннях. Безкоштовний тариф покриває мільйон символів на місяць, а DeepL
використовується лише для тих пар мов, де він перевершує безкоштовні рушії.

**Який стиль показу вибрати?**
Під повідомленням. Решта три працюють, але їх ще доопрацьовують.

**Чи можна користуватися розширенням своєю мовою?**
Так. Воно йде за мовою вашого браузера, а меню вгорі налаштувань перемикає його на будь-яку з
43.

**Чи працює це з 7TV, BTTV і FFZ?**
Так, з будь-яким із них або без них. Назви їхніх емоутів не потрапляють у переклади.

**Чи працює воно на записах VOD і кліпах?**
Так, так само, як і на прямих ефірах.

**Воно зламалося після оновлення Twitch.**
Twitch іноді змінює будову свого чату. Створіть [issue](https://github.com/kilworks/twitch-chat-translator/issues),
і це виправлять.

**Це зроблено в Twitch?**
Ні. Це незалежний проєкт із відкритим кодом, не пов'язаний із Twitch.

## Що нового

У 1.0.0, першому релізі для Twitch:

- Читає чат Twitch у трьох його видах: власний список Twitch (зокрема з BTTV і FFZ), список 7TV і відтворення VOD та кліпів, у спливному чаті, вбудованому чаті, режимі модератора, менеджері трансляції та на мобільних
- Записує переклади в поле введення повідомлення, зберігаючи емоути як слова, і ніколи не перекладає назви емоутів із наборів каналу в 7TV, BTTV і FFZ
- Мова каналу береться від Twitch, видалене повідомлення втрачає переклад, а оформлення фіолетове й іде за темним або світлим чатом Twitch
- Alt+Shift+T вмикає або вимикає переклад, Tab вставляє переклад, лише якщо 7TV або BTTV не дописали емоут щойно перед цим, а кнопка мови розташована на панелі дій під полем введення повідомлення

Кожен випуск із тим, що змінилося, і вимірюванням, яке за цим стоїть:
[Releases](https://github.com/kilworks/twitch-chat-translator/releases) і [CHANGELOG.md](CHANGELOG.md).

## Розробка

```bash
git clone https://github.com/kilworks/twitch-chat-translator.git
cd twitch-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
npm run package:all      # both zips, in release/
npm run dev              # HMR
```

Збірки відтворювані: той самий коміт дає побайтово однакові zip на будь-якій машині, що перевіряється збіркою
`git archive` тегу в порожній папці та порівнянням хешів.

Крім unit-тестів, офлайн-перевірки завантажують зібране розширення в справжній браузер, керують ним і
перевіряють, що воно робить, причому сторінку віддають локально, а рушій перекладу відповідає локально. Їм потрібен
Playwright, який навмисно не є залежністю: вкажіть у `UX_KIT` папку, у `node_modules` якої він є,
або виконайте `npm i -D playwright`.

```bash
node test/e2e/run-gates.mjs --headless                  # all the offline gates, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

Рядки інтерфейсу лежать у `src/shared/i18n/` (спливне вікно й налаштування, ключ - англійський текст) і
`src/content/i18n/` (панель чату, ключ - id, англійський текст як запасний), по одному файлу на мову;
тести вимагають, щоб кожен файл мав повний набір ключів. Тексти для магазинів
лежать у [store/](store/), а випуск - це тег версії: CI збирає, перевіряє й публікує його в обох магазинах.

Стек: Manifest V3, Vite, TypeScript, Preact, Tailwind.
