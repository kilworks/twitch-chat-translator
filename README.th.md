# Twitch Chat Translator

อ่านแชท Twitch ได้ทุกช่องเป็นภาษาของคุณ และตอบกลับเป็นภาษาของช่องนั้น<br>

## ใช้งานอย่างไร

1. ติดตั้งแล้วเปิดสตรีม Twitch ช่องไหนก็ได้ แถบสีม่วงด้านบนของแชทบอกว่าส่วนขยายทำงานอยู่
2. ทุกข้อความจะมีคำแปลขึ้นอยู่ข้างใต้ทันทีที่เข้ามา เป็นภาษาเดียวกับเบราว์เซอร์ของคุณ ทั้งสตรีมสด VOD และ
   คลิปย้อนหลัง
3. พิมพ์ตอบเป็นภาษาของคุณ ตัวอย่างเหนือช่องแชทจะโชว์ข้อความนั้นเป็นภาษาของช่อง:
   กด Tab หรือคลิกที่ตัวอย่าง ข้อความที่แปลแล้วจะเข้าไปแทนที่สิ่งที่พิมพ์

ภาษาของช่องคือภาษาที่สตรีมเมอร์ตั้งไว้บน Twitch จึงไม่ต้องตั้งค่าอะไร ทั้งสองภาษาเปลี่ยนได้ในการตั้งค่า
และจำภาษาที่อ่านแยกตามช่องได้

ถ้าคุณใช้ 7TV หรือ BTTV ด้วย ทั้งสองใช้ Tab เติมอีโมตให้จบ Tab จึงเติมอีโมตก่อน และใส่คำแปลเฉพาะตอนที่ไม่มี
อะไรให้เติม ส่วน Ctrl/Cmd+Enter และการคลิกจะใส่คำแปลเสมอ

## มีอะไรบ้าง

- **43 ภาษา** รวมภาษาที่เขียนจากขวาไปซ้าย (อาหรับ ฮีบรู เปอร์เซีย) และแยกสำเนียงท้องถิ่นไว้ต่างหาก
  (โปรตุเกสแบบบราซิลกับแบบยุโรป จีนตัวย่อกับจีนตัวเต็ม กวางตุ้ง)
- **ใช้ได้ทุกที่ที่มีแชท**: แชทสด ป็อปเอาต์ เอ็มเบด มุมมองมอดเดอเรเตอร์ สตรีมแมเนเจอร์ การเล่นย้อนหลังของ VOD และคลิป
  บน www.twitch.tv, m.twitch.tv และ dashboard.twitch.tv ไม่ว่าจะมี 7TV, BTTV และ FFZ หรือไม่
- **ตัวส่วนขยายก็พูดได้ทุกภาษาเหมือนกัน**: การตั้งค่า ป็อปอัป และแถบแชทมีครบทั้ง 43 ภาษา เลือกจากเมนูที่มีธงประเทศ
- **ฟรีตั้งแต่ติดตั้ง** ด้วย Google Translate ใส่คีย์ DeepL ฟรีของคุณเองเพื่อให้ภาษายุโรปแปลได้ดีขึ้น
  ถ้าเอนจินตัวไหนล่ม MyMemory กับ Lingva จะเข้ามารับช่วงต่อ
- **แปลในเครื่อง** บน Chrome และ Edge ที่เบราว์เซอร์รองรับ: ไม่ใช้เครือข่าย ไม่มีโควตา
  และข้อความไม่ออกจากคอมพิวเตอร์ของคุณเลย
- **ตัวกรอง**: ข้ามบอต ปิดเสียงผู้ใช้หรือช่อง ซ่อนบรรทัดที่มีคำที่กำหนด
  แปลเฉพาะภาษาที่คุณเลือก
- **สร้างมาสำหรับแชทที่วิ่งเร็ว**: ชื่ออีโมตจากชุด 7TV, BTTV และ FFZ ของช่องจะไม่ถูกแปลเลย แม้คุณไม่ได้ใช้ส่วนขยายเหล่านั้น
  ลิงก์และ @mention ถูกแยกไว้ก่อนส่งอะไรออกไป มีอภิธานศัพท์สำหรับชื่อที่เอนจินแปลเพี้ยน และมีแคชคำแปล
- **รูปแบบการแสดงผลสี่แบบ**: ใต้ข้อความ ในบรรทัดเดียวกัน แทนที่ข้อความเดิม หรือแสดงเฉพาะตอนเอาเมาส์ชี้
- **หยุดแค่ช่องเดียว** จากแถบแชทโดยไม่กระทบช่องอื่น เปลี่ยนช่องหรืออัปเดตส่วนขยาย
  แท็บที่เปิดอยู่ก็แปลต่อได้ ไม่ต้องรีโหลด
- **รู้เรื่องการดูแลแชท**: ข้อความที่มอดเดอเรเตอร์ลบ หรือที่ถูกไทม์เอาต์หรือแบน ก็เสียคำแปลไปด้วย
- **หน้าตาแบบ Twitch**: สีม่วง และตามธีมมืดหรือสว่างของแชทเอง เว้นแต่คุณจะเลือกเอง
- Chrome, Brave, Edge และ Firefox

## ติดตั้ง

ดาวน์โหลดไฟล์ zip ของเบราว์เซอร์คุณจาก [Releases](https://github.com/kilworks/twitch-chat-translator/releases/latest) แล้วแตกไฟล์

- Chrome, Brave, Edge (`…-chromium.zip`): เปิด `chrome://extensions` เปิดโหมดนักพัฒนา คลิก Load unpacked แล้วเลือกโฟลเดอร์
- Firefox 121+ (`…-firefox.zip`): เปิด `about:debugging#/runtime/this-firefox` คลิก Load Temporary Add-on แล้วเลือก `manifest.json`
  Firefox จะลืมส่วนเสริมชั่วคราวเมื่อรีสตาร์ท

ตัวที่ติดตั้งแบบนี้จะไม่อัปเดตเอง: ไอคอนจะมีป้ายขึ้นเมื่อมีเวอร์ชันใหม่ และ
ป็อปอัปจะมีลิงก์ไปที่รุ่นล่าสุด

## เอนจินแปลภาษา

ผู้ให้บริการสี่ราย ต่อกันเป็นลูกโซ่: ตัวไหนล่ม ตัวถัดไปรับช่วงต่อ ลำดับกำหนดเองได้

| ผู้ให้บริการ | คีย์ | หมายเหตุ |
|---|---|---|
| Google | ไม่ต้องใช้ | ค่าเริ่มต้น ใช้ได้ทันที |
| DeepL | ฟรี | ดีที่สุดกับภาษายุโรป มี[คีย์ฟรี](https://www.deepl.com/pro-api) 1 ล้านตัวอักษรต่อเดือน |
| MyMemory | ไม่ต้องใช้ | ตัวสำรอง |
| Lingva | ไม่ต้องใช้ | ตัวสำรอง ใช้อินสแตนซ์สาธารณะ เว้นแต่คุณจะชี้ไปที่ของตัวเอง |

ตัวแปลในตัวของ Chromium ไม่ใช้เครือข่ายและไม่มีโควตา Chrome และ Edge เวอร์ชัน 138 ขึ้นไป
เปิดใช้ได้ แต่ไม่ใช่ทุกเครื่อง และแต่ละคู่ภาษาต้องดาวน์โหลดโมเดลหนึ่งครั้ง
ด้วยการคลิกหนึ่งทีจากแถบ Firefox ไม่มีฟีเจอร์นี้ ที่ไหนไม่มี
ลูกโซ่คลาวด์จะเข้ามารับช่วงและทุกอย่างยังทำงานต่อได้

## การตั้งค่า

คลิกรูปเฟืองบนแถบแชท หรือคลิกขวาที่ไอคอนส่วนขยายแล้วเลือก ตัวเลือก

- **บริการ** (Providers): ลำดับเอนจิน คีย์ DeepL ของคุณ และโหมด: ในเครื่องก่อน คลาวด์ก่อน หรือเฉพาะในเครื่อง
- **การแสดงผล** (Display): ภาษาปลายทาง รูปแบบการแสดง ข้อความต้นฉบับและป้ายภาษา ขนาดตัวอักษร ระยะห่างบรรทัด
  แบบอักษร สีเน้น ธีมแชท ตัวอย่างข้อความที่พิมพ์ และสิ่งที่เกิดขึ้นเมื่อคลิกมัน
- **ตัวกรอง** (Filters): บอต ผู้ใช้ ช่อง คำสำคัญ ภาษาต้นทาง และอภิธานศัพท์สำหรับคำแทนที่
- **ขั้นสูง** (Advanced): ขนาดและอายุแคช การแปลพร้อมกัน ขีดจำกัดต่อช่อง สำรองและกู้คืนข้อมูล
- **กิจกรรม** (Activity): จำนวนข้อความที่แปล แคชที่พบ ทุกภาษาที่เจอในแชท และเหตุผลที่ 50
  บรรทัดล่าสุดถูกแปลหรือถูกข้าม
- **คีย์ลัด**: Alt+Shift+T เปิดหรือปิดการแปลแชท (Alt+T คือโหมดโรงภาพยนตร์ของ Twitch) Alt+W เปิดหรือปิดตัวอย่างข้อความที่พิมพ์
  ตั้งปุ่มใหม่ได้ทั้งสองอย่างในคีย์ลัดส่วนขยายของเบราว์เซอร์
- ปุ่มภาษาบนแถบการกระทำของแชท ใต้ช่องพิมพ์ข้อความ: คลิกครั้งเดียวเปิดรายการภาษาที่คุณเขียน พิมพ์เพื่อกรอง
  ปุ่มบนสุดของแชทตั้งภาษาที่คุณอ่าน

## ความเป็นส่วนตัว

ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ของผม และไม่มีการวิเคราะห์ เว้นแต่คุณยินยอมให้ส่งตัวเลขแบบไม่ระบุตัวตนวันละครั้งไปยัง Google Analytics (เอนจินที่ใช้ ข้อผิดพลาด ความเร็ว ไม่มีข้อความ ชื่อ หรือช่องของคุณเด็ดขาด) ข้อความแชท และร่างของคุณขณะที่เปิดตัวอย่างข้อความที่พิมพ์ ไปที่ผู้ให้บริการแปลที่คุณเลือกเท่านั้น
ไม่ไปที่อื่น และในโหมดแปลในเครื่องก็ไม่ไปที่นั่นด้วย เพื่อรู้ภาษาของช่อง ส่วนขยายจะถาม Twitch เรื่องภาษาที่ช่องออกอากาศและ id ของช่อง และเพื่อไม่ให้ชื่ออีโมตถูกแปล จะถาม 7TV, BetterTTV และ FrankerFaceZ เรื่องชื่ออีโมตของช่อง ซึ่งทำให้พวกเขารู้ id ของช่องนั้นและไม่มีอะไรอื่น เวอร์ชันที่ติดตั้งจากสโตร์ไม่ส่งคำขออื่นใดทั้งสิ้น
เวอร์ชันที่ติดตั้งเองจะถาม GitHub หาแท็กของรุ่นล่าสุด อย่างมากทุกหกชั่วโมง เพื่อดูว่าควรแสดงป้ายอัปเดตหรือไม่

## มีอะไรใหม่

ในรุ่น 1.0.0 รุ่นแรกสำหรับ Twitch:

- อ่านแชท Twitch ได้ทั้งสามรูปแบบ: รายการของ Twitch เอง (รวมถึงเมื่อมี BTTV และ FFZ) รายการของ 7TV และการเล่นย้อนหลังของ VOD และคลิป ในป็อปเอาต์ เอ็มเบด มุมมองมอดเดอเรเตอร์ สตรีมแมเนเจอร์ และมือถือ
- เขียนคำแปลลงในช่องพิมพ์ข้อความโดยคงอีโมตเป็นคำ และไม่แปลชื่ออีโมตของชุด 7TV, BTTV และ FFZ ของช่อง
- ภาษาของช่องมาจาก Twitch ข้อความที่ถูกลบจะเสียคำแปล และหน้าตาเป็นสีม่วงตามแชทมืดหรือสว่างของ Twitch
- Alt+Shift+T เปิดหรือปิดการแปล Tab ใส่คำแปลเฉพาะตอนที่ 7TV หรือ BTTV ไม่ได้เพิ่งเติมอีโมตให้จบ และปุ่มภาษาอยู่ในแถบการกระทำใต้ช่องพิมพ์ข้อความ

ทุกรุ่น พร้อมสิ่งที่เปลี่ยนและตัวเลขที่วัดได้:
[Releases](https://github.com/kilworks/twitch-chat-translator/releases) และ [CHANGELOG.md](CHANGELOG.md)

## การพัฒนา

```bash
git clone https://github.com/kilworks/twitch-chat-translator.git
cd twitch-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
npm run package:all      # both zips, in release/
npm run dev              # HMR
```

บิลด์ทำซ้ำได้: คอมมิตเดียวกันให้ไฟล์ zip ที่ตรงกันทุกไบต์บนทุกเครื่อง ตรวจโดยการบิลด์
`git archive` ของแท็กในโฟลเดอร์ว่างแล้วเทียบแฮช

นอกจากยูนิตเทสต์ ยังมี gate แบบออฟไลน์ที่โหลดส่วนขยายที่บิลด์แล้วเข้าเบราว์เซอร์จริง สั่งงานมัน แล้วตรวจว่า
มันทำอะไร โดยหน้าเว็บเสิร์ฟในเครื่องและเอนจินแปลตอบกลับในเครื่อง ต้องใช้
Playwright ซึ่งตั้งใจไม่ใส่เป็น dependency: ชี้ `UX_KIT` ไปที่โฟลเดอร์ที่ `node_modules` มีมันอยู่
หรือรัน `npm i -D playwright`

```bash
node test/e2e/run-gates.mjs --headless                  # all the offline gates, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

สตริงของหน้าตาส่วนขยายอยู่ใน `src/shared/i18n/` (ป็อปอัปและตัวเลือก ใช้ข้อความภาษาอังกฤษเป็นคีย์) และ
`src/content/i18n/` (แถบแชท ใช้ id เป็นคีย์ โดยมีข้อความภาษาอังกฤษเป็นตัวสำรอง) หนึ่งไฟล์ต่อภาษา
เทสต์บังคับให้ทุกไฟล์มีคีย์ครบชุด ข้อความของสโตร์
อยู่ใน [store/](store/) และการปล่อยรุ่นคือการติดแท็กเวอร์ชัน: CI จะบิลด์ ตรวจ และเผยแพร่ไปทั้งสอง
สโตร์

Stack: Manifest V3, Vite, TypeScript, Preact, Tailwind
