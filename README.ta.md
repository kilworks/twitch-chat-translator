# Twitch Chat Translator

எந்த Twitch சாட்டையும் உன் மொழியில் படி, பதிலை சேனலின் மொழியில் சொல்.<br>

## எப்படி வேலை செய்கிறது

1. இன்ஸ்டால் பண்ணி ஏதாவது ஒரு Twitch ஸ்ட்ரீமைத் திற. சாட்டின் மேலே ஒரு ஊதா பார் இது ஆன் ஆகியிருப்பதைக் காட்டும்.
2. ஒவ்வொரு மெசேஜும் வந்த உடனே அதன் மொழிபெயர்ப்பு அதன் கீழேயே தெரியும், உன் பிரவுசரின் மொழியில்.
   லைவ் ஸ்ட்ரீம், VOD, கிளிப் எல்லாவற்றிலும்.
3. உன் மொழியில் பதிலைத் தட்டச்சு செய். சாட் பெட்டிக்கு மேலே உள்ள முன்னோட்டம் அதை சேனலின் மொழியில்
   காட்டும்: Tab அழுத்து அல்லது அதன் மேல் கிளிக் செய், நீ எழுதியதற்குப் பதிலாக அந்த வடிவம் வந்துவிடும்.

சேனலின் மொழி என்பது ஸ்ட்ரீமர் Twitch-இல் அமைத்தது, அதனால் எதையும் கான்ஃபிகர் பண்ண வேண்டாம். இரண்டு மொழிகளையும்
செட்டிங்ஸில் மாற்றலாம், படிக்கும் மொழியை ஒவ்வொரு சேனலுக்கும் தனியாக நினைவில் வைக்கவும் முடியும்.

நீ 7TV அல்லது BTTV-யும் பயன்படுத்தினால், அவை எமோட்டை முடிக்க Tab-ஐப் பயன்படுத்துகின்றன. அப்போது Tab முதலில் எமோட்டை முடிக்கும்,
முடிக்க எதுவும் இல்லாதபோது மட்டுமே மொழிபெயர்ப்பைச் செருகும். Ctrl/Cmd+Enter-உம் கிளிக்கும் எப்போதும் செருகும்.

## என்ன கிடைக்கும்

- **43 மொழிகள்**, வலமிருந்து இடமாக எழுதப்படுபவையும் சேர்த்து (அரபு, ஹீப்ரு, பாரசீகம்), பிராந்திய வகைகள் தனித்தனியாக
  (பிரேசில் மற்றும் ஐரோப்பிய போர்ச்சுகீசு, எளிய மற்றும் பாரம்பரிய சீனம், கான்டனீஸ்)
- **சாட் எங்கெல்லாம் இருக்கிறதோ அங்கெல்லாம்**: லைவ் சாட், பாப்அவுட், எம்பெட், மாடரேட்டர் வியூ, ஸ்ட்ரீம் மேனேஜர், VOD மற்றும் கிளிப் ரீப்ளே,
  www.twitch.tv, m.twitch.tv, dashboard.twitch.tv-இல், 7TV, BTTV, FFZ இருந்தாலும் இல்லாவிட்டாலும்
- **எக்ஸ்டென்ஷனும் இந்த மொழிகளிலேயே பேசுகிறது**: செட்டிங்ஸ், பாப்அப், சாட் பார் எல்லாம் 43-இலும், கொடிகள் உள்ள மெனுவில் தேர்ந்தெடுக்கலாம்
- **ஆரம்பத்திலிருந்தே இலவசம்**, Google Translate மூலம். ஐரோப்பிய மொழிகளில் நல்ல தரத்துக்கு உன் இலவச DeepL
  key-யைச் சேர்த்துக்கொள்; ஒரு இன்ஜின் தோற்றால் MyMemory-யும் Lingva-வும் எடுத்துக்கொள்ளும்
- **டிவைஸிலேயே மொழிபெயர்ப்பு** Chrome, Edge-இல், பிரவுசர் தரும் இடத்தில்: நெட்வொர்க் வேண்டாம், கோட்டா வேண்டாம், டெக்ஸ்ட் உன்
  கம்ப்யூட்டரை விட்டு வெளியே போவதே இல்லை
- **ஃபில்டர்கள்**: பாட்களைத் தவிர்க்கலாம், யூசர்கள் அல்லது சேனல்களை மியூட் பண்ணலாம், குறிப்பிட்ட வார்த்தை உள்ள
  வரிகளை மறைக்கலாம், நீ தேர்ந்தெடுக்கும் மொழிகளை மட்டும் மொழிபெயர்க்கலாம்
- **வேகமான சாட்களுக்காக உருவாக்கப்பட்டது**: சேனலின் 7TV, BTTV, FFZ தொகுப்புகளின் எமோட் பெயர்கள் ஒருபோதும் மொழிபெயர்க்கப்படாது, அந்த
  எக்ஸ்டென்ஷன்களை நீ பயன்படுத்தாவிட்டாலும், லிங்குகளும் @மென்ஷன்களும் எதுவும் அனுப்பப்படும் முன்பே ஒதுக்கி வைக்கப்படும், இன்ஜின்கள் கெடுத்துவிடும் பெயர்களுக்கான சொற்களஞ்சியம், மொழிபெயர்ப்பு கேஷ்
- **நான்கு காட்சி பாணிகள்**: மெசேஜின் கீழே, அதே வரியில், மெசேஜுக்குப் பதிலாக, அல்லது ஹோவர் செய்தால் மட்டும்
- **ஒரு சேனலை இடைநிறுத்து** சாட் பாரிலிருந்து, மற்றவற்றை நிறுத்தாமல். சேனல் மாற்றினாலும் எக்ஸ்டென்ஷன்
  அப்டேட் ஆனாலும் திறந்த டேப்கள் ரீலோடு இல்லாமல் தொடர்ந்து மொழிபெயர்க்கும்
- **மாடரேஷனை அறியும்**: மாடரேட்டர் நீக்கிய மெசேஜ், அல்லது டைம்அவுட் அல்லது பேன் நீக்கியது, தன் மொழிபெயர்ப்பையும் இழக்கும்
- **Twitch போலவே தெரியும்**: ஊதா நிறம், நீ வேறொன்றைத் தேர்ந்தெடுக்காவிட்டால் சாட்டின் சொந்த டார்க் அல்லது லைட் தீமைப் பின்பற்றும்

## இன்ஸ்டால்

உன் பிரவுசருக்கான zip-ஐ [Releases](https://github.com/kilworks/twitch-chat-translator/releases/latest) பக்கத்திலிருந்து டவுன்லோடு செய்து அன்சிப் பண்ணு.

- Chrome, Brave, Edge (`…-chromium.zip`): `chrome://extensions` திற, Developer mode ஆன் செய், Load unpacked கிளிக் செய், ஃபோல்டரைத் தேர்ந்தெடு.
- Firefox 121+ (`…-firefox.zip`): `about:debugging#/runtime/this-firefox` திற, Load Temporary Add-on கிளிக் செய், `manifest.json`-ஐத் தேர்ந்தெடு.
  Firefox ரீஸ்டார்ட் ஆனால் தற்காலிக ஆட்-ஆனை மறந்துவிடும்.

இப்படி இன்ஸ்டால் செய்த காப்பி தானாக அப்டேட் ஆகாது: புதிய வெர்ஷன் இருந்தால் அதன் ஐகானில்
ஒரு பேட்ஜ் தெரியும், பாப்அப் சமீபத்திய ரிலீஸுக்கு லிங்க் தரும்.

Chromium-இன் உள்ளமைந்த மொழிபெயர்ப்பானுக்கு நெட்வொர்க் வேண்டாம், கோட்டாவும் வேண்டாம். Chrome, Edge 138 மற்றும் அதற்குப் பிந்தையவற்றில்
இது கிடைக்கலாம், எல்லா காப்பிகளிலும் இல்லை, ஒவ்வொரு மொழி ஜோடிக்கும் அதன் மாடலை ஒருமுறை டவுன்லோடு செய்ய வேண்டும், பாரில் ஒரு கிளிக்கில்.
Firefox-இல் இது இல்லை. இல்லாத இடங்களில் கிளவுட் சங்கிலி எடுத்துக்கொள்ளும், எதுவும் உடையாது.

## செட்டிங்ஸ்

சாட் பாரில் உள்ள கியரைக் கிளிக் செய், அல்லது எக்ஸ்டென்ஷன் ஐகானில் ரைட்-கிளிக் செய்து Options-ஐத் தேர்ந்தெடு.

- **சேவைகள்**: இன்ஜின் வரிசை, உன் DeepL key, முறை: முதலில் டிவைஸ், முதலில் கிளவுட், அல்லது டிவைஸ் மட்டும்
- **காட்சி**: மொழிபெயர்ப்பு மொழி, காட்சி பாணி, மூல உரை மற்றும் மொழிக் குறி, எழுத்தின் அளவு, வரி இடைவெளி,
  எழுத்துரு, முக்கிய நிறம், சாட் தீம், தட்டச்சு முன்னோட்டம், அதைக் கிளிக் செய்தால் என்ன நடக்கும்
- **வடிகட்டிகள்**: பாட்கள், யூசர்கள், சேனல்கள், கீவேர்டுகள், மூல மொழிகள், மாற்றுகளுக்கான சொற்களஞ்சியம்
- **மேம்பட்டவை**: கேஷ் அளவும் காலமும், ஒரே நேரக் கோரிக்கைகள், ஒவ்வொரு சேனலுக்கும் ரேட் லிமிட், பேக்கப் மற்றும் ரீஸ்டோர்
- **செயல்பாடு**: மொழிபெயர்க்கப்பட்ட மெசேஜ்கள், கேஷ் ஹிட்கள், சாட்டில் பார்த்த ஒவ்வொரு மொழியும், கடைசி 50
  வரிகளில் ஒவ்வொன்றும் ஏன் மொழிபெயர்க்கப்பட்டது அல்லது விடப்பட்டது
- **கீபோர்டு**: Alt+Shift+T சாட் மொழிபெயர்ப்பை ஆன் அல்லது ஆஃப் செய்யும் (Alt+T என்பது Twitch-இன் தியேட்டர் மோடு), Alt+W தட்டச்சு முன்னோட்டத்தை.
  இரண்டையும் உன் பிரவுசரின் எக்ஸ்டென்ஷன் ஷார்ட்கட்களில் மாற்றலாம்
- சாட்டின் ஆக்ஷன் பாரில், மெசேஜ் பெட்டிக்குக் கீழே உள்ள மொழி பட்டன்: ஒரு கிளிக் நீ எழுதும் மொழிகளின் பட்டியலைத் திறக்கும்,
  தட்டச்சு செய்தால் அது வடிகட்டப்படும். சாட்டின் மேலே உள்ளது நீ படிக்கும் மொழியை அமைக்கும்

## FAQ

**மெசேஜ்கள் மொழிபெயர்க்கப்படவில்லை.**
செட்டிங்ஸில் செயல்பாடு டேபைத் திறந்து "முடிவுகளைப் படிக்கவும்" (Read decisions) அழுத்து: கடைசி 50 வரிகளைப் பட்டியலிட்டு,
ஒவ்வொன்றும் ஏன் மொழிபெயர்க்கப்பட்டது அல்லது விடப்பட்டது என்று சொல்லும். விடப்படும் பெரும்பாலான வரிகள் வேண்டுமென்றே
விடப்படுபவை: ஒரே யூசர் தன்னையே திரும்பச் சொல்வது, மிகச் சிறிய வரிகள், எமோஜி அல்லது சிரிப்பு மட்டும், அல்லது ஏற்கனவே படிக்கும் மொழியிலேயே இருப்பவை. டேபில் எதுவுமே தெரியவில்லை என்றால்
எக்ஸ்டென்ஷனுக்குச் சாட்டே தெரியவில்லை என்று அர்த்தம்: தயவுசெய்து ஒரு issue திற.

**ஊதா பார் மறைந்துவிட்டது.**
பக்கத்தை ரெஃப்ரெஷ் செய். மறுபடியும் நடந்தால், சேனலையும் அதற்கு முன் நீ செய்ததையும் எழுதி ஒரு
[issue](https://github.com/kilworks/twitch-chat-translator/issues) திற.

**நல்ல மொழிபெயர்ப்புகள் கிடைக்க என்ன செய்வது?**
செட்டிங்ஸில் ஒரு இலவச DeepL key-யைச் சேர். இலவச அடுக்கு மாதம் 10 லட்சம் எழுத்துகளை உள்ளடக்கும், DeepL இலவச
இன்ஜின்களை விட நன்றாக இருக்கும் மொழி ஜோடிகளுக்கு மட்டுமே செலவாகும்.

**எந்த காட்சி பாணியைப் பயன்படுத்தலாம்?**
மெசேஜின் கீழே என்பது. மற்ற மூன்றும் வேலை செய்யும், இன்னும் மெருகேற்றப்பட்டு வருகின்றன.

**எக்ஸ்டென்ஷனை என் மொழியில் பயன்படுத்த முடியுமா?**
முடியும். இது உன் பிரவுசரின் மொழியைப் பின்பற்றும், செட்டிங்ஸின் மேலே உள்ள மெனு அதை 43-இல் எதற்கும் மாற்றும்.

**7TV, BTTV, FFZ உடன் வேலை செய்கிறதா?**
ஆம், அவற்றில் எதனுடனும் அல்லது எதுவும் இல்லாமலும். அவற்றின் எமோட் பெயர்கள் மொழிபெயர்க்கப்படாது.

**VOD மற்றும் கிளிப்களில் வேலை செய்கிறதா?**
ஆம், லைவ் ஸ்ட்ரீம்களில் போலவே.

**Twitch அப்டேட்டுக்குப் பிறகு உடைந்துவிட்டது.**
Twitch சில சமயம் அதன் சாட் கட்டமைப்பை மாற்றும். ஒரு [issue](https://github.com/kilworks/twitch-chat-translator/issues)
திற, பேட்ச் வந்துவிடும்.

**இதை Twitch தான் உருவாக்கியதா?**
இல்லை. இது ஒரு சுதந்திரமான ஓப்பன்-சோர்ஸ் ப்ராஜெக்ட், Twitch-உடன் தொடர்பு இல்லை.

## டெவலப்மென்ட்

```bash
git clone https://github.com/kilworks/twitch-chat-translator.git
cd twitch-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
```

பில்டுகளை மீண்டும் உருவாக்கலாம்: ஒரே கமிட் எந்த மெஷினிலும் பைட்டுக்குப் பைட் ஒரே மாதிரியான zip-களைத் தரும்,
டேக்கின் `git archive`-ஐ ஒரு காலி ஃபோல்டரில் பில்டு செய்து ஹேஷ்களை ஒப்பிட்டுச் சரிபார்க்கப்படுகிறது.

யூனிட் டெஸ்ட்களுக்கு அப்பால், ஆஃப்லைன் கேட்கள் பில்டு செய்த எக்ஸ்டென்ஷனை உண்மையான பிரவுசரில் லோடு செய்து,
இயக்கி, அது என்ன செய்கிறது என்று சரிபார்க்கின்றன, பக்கம் லோக்கலாகப் பரிமாறப்படும், மொழிபெயர்ப்பு இன்ஜினும் லோக்கலாகவே
பதில் தரும். இவற்றுக்கு Playwright வேண்டும், அது வேண்டுமென்றே டிபென்டென்சி இல்லை: `UX_KIT`-ஐ அது `node_modules`-இல் உள்ள
ஃபோல்டரைக் காட்டும்படி வை, அல்லது `npm i -D playwright` ஓட்டு.

```bash
node test/e2e/run-gates.mjs --headless                  # all the offline gates, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

இன்டர்ஃபேஸ் ஸ்ட்ரிங்குகள் `src/shared/i18n/`-இல் உள்ளன (பாப்அப் மற்றும் ஆப்ஷன்ஸ், ஆங்கில உரையே key) மற்றும்
`src/content/i18n/`-இல் (சாட் பார், id-யே key, ஆங்கில உரை ஃபால்பேக்), ஒரு மொழிக்கு ஒரு ஃபைல்; டெஸ்ட்கள் ஒவ்வொரு
ஃபைலும் முழு key தொகுப்பைக் கொண்டிருக்க வேண்டும் என்று கோருகின்றன. ஸ்டோர் உரைகள் [store/](store/)-இல் உள்ளன, ரிலீஸ்
என்பது ஒரு வெர்ஷன் டேக்: CI அதை பில்டு செய்து, சரிபார்த்து, இரண்டு ஸ்டோர்களிலும் பப்ளிஷ் செய்யும்.

ஸ்டாக்: Manifest V3, Vite, TypeScript, Preact, Tailwind.
