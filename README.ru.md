# Twitch Chat Translator

Читайте чат любого стрима на Twitch на своём языке и отвечайте на языке канала.<br>

## Как это работает

1. Установите расширение и откройте любую трансляцию на Twitch. Фиолетовая полоса вверху чата показывает, что оно
   включено.
2. Каждое сообщение получает перевод прямо под собой, по мере поступления, на языке вашего браузера. И на
   прямых эфирах, и на записях VOD, и на клипах.
3. Наберите ответ на своём языке. Предпросмотр над полем ввода покажет его на языке канала: нажмите Tab или
   щёлкните по нему, и этот вариант заменит набранный текст.

Язык канала это тот, который стример указал на Twitch, так что настраивать ничего не нужно. Оба языка меняются в настройках,
а язык чтения можно запоминать для каждого канала отдельно.

Если вы пользуетесь ещё и 7TV или BTTV, они используют Tab, чтобы дописать эмоут. Тогда Tab сначала дописывает
эмоут, а перевод вставляет, только если дописывать было нечего. Ctrl/Cmd+Enter и щелчок вставляют его всегда.

## Что вы получаете

- **43 языка**, включая письмо справа налево (арабский, иврит, персидский); региональные варианты не
  смешиваются (бразильский и европейский португальский, упрощённый и традиционный китайский, кантонский)
- **Везде, где есть чат**: прямой чат, всплывающий чат, встроенный чат, режим модератора, менеджер трансляции,
  воспроизведение VOD и клипов, на www.twitch.tv, m.twitch.tv и dashboard.twitch.tv, с 7TV, BTTV и FFZ или без них
- **Расширение говорит на них тоже**: настройки, всплывающее окно и панель чата на всех 43 языках, выбираются из меню с флагами
- **Бесплатно сразу** с Google Translate. Добавьте свой бесплатный ключ DeepL ради более качественного
  перевода европейских языков; MyMemory и Lingva подхватывают, когда движок отказывает
- **Перевод на самом устройстве** в Chrome и Edge, где браузер его предлагает: без сети, без квоты, и текст
  никогда не покидает ваш компьютер
- **Фильтры**: пропускать ботов, заглушать пользователей или каналы, скрывать строки с определённым словом,
  переводить только выбранные языки
- **Сделано для быстрых чатов**: названия эмоутов из наборов канала в 7TV, BTTV и FFZ никогда не переводятся, даже
  если эти расширения у вас не установлены, ссылки и @упоминания откладываются в сторону до отправки
  чего-либо, глоссарий для имён, которые движки коверкают, кэш переводов
- **Четыре стиля отображения**: под сообщением, в той же строке, вместо него или только при наведении
- **Пауза для одного канала** прямо с панели чата, остальные продолжают работать. При смене канала или
  обновлении расширения открытые вкладки продолжают переводить без перезагрузки
- **С учётом модерации**: сообщение, удалённое модератором, а также из-за тайм-аута или бана, тоже теряет свой перевод
- **Выглядит как Twitch**: фиолетовый, и следует собственной тёмной или светлой теме чата, пока вы не выберете свою
- Chrome, Brave, Edge и Firefox

## Установка

Скачайте zip для своего браузера на странице [Releases](https://github.com/kilworks/twitch-chat-translator/releases/latest) и распакуйте его.

- Chrome, Brave, Edge (`…-chromium.zip`): откройте `chrome://extensions`, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку.
- Firefox 121+ (`…-firefox.zip`): откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение» и выберите `manifest.json`.
  Firefox забывает временное дополнение при перезапуске.

Копия, установленная так, сама не обновляется: на её значке появляется отметка, когда есть более
новая версия, а всплывающее окно ведёт к последнему релизу.

## Движки перевода

Четыре движка выстроены в цепочку: когда один отказывает, подхватывает следующий. Порядок задаёте вы.

| Движок | Ключ | Примечание |
|---|---|---|
| Google | не нужен | по умолчанию, работает сразу |
| DeepL | бесплатный | лучше всего на европейских языках, [бесплатный ключ](https://www.deepl.com/pro-api) на 1 миллион символов в месяц |
| MyMemory | не нужен | запасной |
| Lingva | не нужен | запасной, на публичном экземпляре, если вы не укажете свой |

Встроенному переводчику Chromium не нужны ни сеть, ни квота. Chrome и Edge 138 и новее
могут его предложить, хотя не каждая копия это делает, а для каждой пары языков модель нужно скачать один
раз, одним щелчком с панели. В Firefox его нет. Там, где его нет, подхватывает облачная цепочка, и ничего не
ломается.

## Настройки

Щёлкните по шестерёнке на панели чата или нажмите правой кнопкой на значок расширения и выберите «Параметры».

- **Движки**: порядок движков, ваш ключ DeepL и режим: сначала на устройстве, сначала в облаке или только на
  устройстве
- **Отображение**: целевой язык, стиль отображения, оригинальный текст и метка языка, размер текста,
  межстрочный интервал, шрифт, акцентный цвет, тема чата, предпросмотр ответа и что делает щелчок по нему
- **Фильтры**: боты, пользователи, каналы, ключевые слова, исходные языки и глоссарий замен
- **Дополнительно**: размер и срок жизни кэша, число одновременных запросов, лимит на канал, резервная копия и
  восстановление
- **Активность**: переведённые сообщения, попадания в кэш, все языки, замеченные в чате, и почему каждая из
  последних 50 строк была переведена или оставлена как есть
- **Клавиатура**: Alt+Shift+T включает или выключает перевод чата (Alt+T это режим театра Twitch), Alt+W предпросмотр
  ответа. Обе комбинации можно переназначить в сочетаниях клавиш расширений вашего браузера
- Кнопка языка на панели действий чата, под полем ввода сообщения: один щелчок открывает список языков, на которых
  вы пишете, набор текста фильтрует его. Кнопка вверху чата задаёт язык, на котором вы читаете

## Конфиденциальность

Ни аккаунта, ни моего сервера, и никакой аналитики, если вы не согласитесь на анонимный ежедневный подсчёт для Google Analytics (использованные движки, ошибки, скорость, никогда ваши сообщения, имена или каналы). Сообщения чата и ваш черновик, пока включён предпросмотр ответа, уходят выбранному вами движку перевода и никуда
больше, а в режиме на устройстве не уходят и туда. Чтобы узнать язык канала, оно запрашивает у Twitch язык трансляции и id канала, а чтобы названия эмоутов не попадали в переводы, запрашивает у 7TV, BetterTTV и FrankerFaceZ названия эмоутов канала, и это сообщает им id этого канала и ничего больше. Копия, установленная из магазина, не делает никаких других
запросов. Копия, установленная вручную, запрашивает у GitHub тег последнего релиза, не чаще раза в шесть
часов, чтобы знать, показывать ли отметку об обновлении. [Подробности](PRIVACY.md)

## Вопросы и ответы

**Сообщения не переводятся.**
Откройте вкладку «Активность» в настройках и нажмите «Прочитать решения»: она покажет последние 50 строк и
почему каждая была переведена или оставлена как есть. Большинство пропущенных строк пропущено намеренно: один и
тот же пользователь повторяется, строки слишком короткие, только эмодзи или смех, либо уже на языке чтения. Если вкладка не показывает ничего, значит,
расширение не видит чат: пожалуйста, откройте issue.

**Фиолетовая полоса пропала.**
Обновите страницу. Если это повторится, откройте [issue](https://github.com/kilworks/twitch-chat-translator/issues)
с указанием канала и того, что вы делали до этого.

**Как получить более качественный перевод?**
Добавьте бесплатный ключ DeepL в настройках. Бесплатный тариф покрывает миллион символов в месяц, а DeepL
тратится только на те пары языков, где он лучше бесплатных движков.

**Какой стиль отображения выбрать?**
Под сообщением. Остальные три работают, но их ещё донастраивают.

**Можно ли пользоваться расширением на моём языке?**
Да. Оно следует языку вашего браузера, а меню вверху настроек переключает его на любой из 43.

**Работает ли это с 7TV, BTTV и FFZ?**
Да, с любым из них или без них. Названия их эмоутов не попадают в переводы.

**Работает ли это на записях VOD и клипах?**
Да, так же, как на прямых эфирах.

**Перестало работать после обновления Twitch.**
Twitch иногда меняет устройство своего чата. Откройте [issue](https://github.com/kilworks/twitch-chat-translator/issues),
и это поправят.

**Это сделал Twitch?**
Нет. Это независимый проект с открытым исходным кодом, не связанный с Twitch.

## Что нового

В 1.0.0, первом релизе для Twitch:

- Читает чат Twitch в трёх его видах: собственный список Twitch (в том числе с BTTV и FFZ), список 7TV и воспроизведение VOD и клипов, во всплывающем чате, встроенном чате, режиме модератора, менеджере трансляции и на мобильных
- Записывает переводы в поле ввода сообщения, сохраняя эмоуты как слова, и никогда не переводит названия эмоутов из наборов канала в 7TV, BTTV и FFZ
- Язык канала берётся у Twitch, удалённое сообщение теряет перевод, а оформление фиолетовое и следует тёмному или светлому чату Twitch
- Alt+Shift+T включает или выключает перевод, Tab вставляет перевод, только если 7TV или BTTV не дописали эмоут прямо перед этим, а кнопка языка находится на панели действий под полем ввода сообщения

Каждый релиз, с описанием изменений и измерениями, на которых они основаны:
[Releases](https://github.com/kilworks/twitch-chat-translator/releases) и [CHANGELOG.md](CHANGELOG.md).

## Разработка

```bash
git clone https://github.com/kilworks/twitch-chat-translator.git
cd twitch-chat-translator
npm ci
npm run release:check    # typecheck, lint, модульные тесты, сборка: проверка, через которую проходит каждый пакет
npm run build:firefox    # сборка для Firefox, в ту же папку dist/
npm run package:all      # оба zip-архива, в release/
npm run dev              # HMR
```

Сборки воспроизводимы: один и тот же коммит даёт побайтово идентичные zip-архивы на любой машине, что
проверяется сборкой `git archive` тега в пустой папке и сравнением хешей.

Помимо модульных тестов, офлайн-проверки загружают собранное расширение в настоящий браузер, управляют им
и проверяют, что оно делает, при этом страница отдаётся локально, а движок перевода отвечает локально. Им
нужен Playwright, который намеренно не является зависимостью: укажите в `UX_KIT` папку, в `node_modules`
которой он лежит, или выполните `npm i -D playwright`.

```bash
node test/e2e/run-gates.mjs --headless                  # все офлайн-проверки, без окна
node test/e2e/store-shots-fixture.mjs --lang=ja         # скриншоты для магазина, на одном языке карточки
node test/e2e/store-shots-fixture.mjs --gif             # английские скриншоты для магазина, картинки README и этот GIF
```

Строки интерфейса лежат в `src/shared/i18n/` (всплывающее окно и настройки, ключ это английский текст) и
`src/content/i18n/` (панель чата, ключ это id, английский текст как запасной вариант), по одному файлу на
язык; тесты требуют от каждого файла полного набора ключей. Тексты для магазинов лежат в [store/](store/), а
релиз это тег версии: CI собирает, проверяет и публикует его в обоих магазинах.

Стек: Manifest V3, Vite, TypeScript, Preact, Tailwind.
