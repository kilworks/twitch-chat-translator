Libre, walang account, walang kailangang i-set up. 43 wika, sa chat at pati sa mismong extension.

## Paano ito gumagana

1. I-install ito at buksan ang kahit anong Twitch stream. Ang purple na bar sa taas ng chat ang nagsasabing naka-on na ito.
2. Bawat mensahe ay may salin agad sa ilalim habang dumarating, sa wika ng browser mo. Live stream, VOD at
   clip man.
3. Mag-type ng sagot sa sarili mong wika. May preview sa ibabaw ng chat box na nagpapakita nito sa wika ng channel:
   pindutin ang Tab o i-click ito, at papalitan nito ang tinype mo.

Ang wika ng channel ay ang itinakda ng streamer sa Twitch, kaya wala kang kailangang i-configure. Puwedeng baguhin ang
dalawang wika sa mga setting, at puwedeng tandaan ang wikang binabasa mo kada channel.

Kung gumagamit ka rin ng 7TV o BTTV, Tab din ang gamit nila para tapusin ang isang emote. Ang Tab ay tatapusin muna ang
emote, at isisingit lang ang salin kapag wala itong tatapusin. Laging isinisingit ito ng Ctrl/Cmd+Enter at ng click.

## Ano ang makukuha mo

- **43 wika**, kasama ang mga nakasulat mula kanan pakaliwa (Arabic, Hebrew, Persian), at magkahiwalay ang mga regional variant
  (Brazilian at European Portuguese, Simplified at Traditional Chinese, Cantonese)
- **Saanman may chat**: live chat, popout, embed, moderator view, ang stream manager, VOD at clip replay, sa
  www.twitch.tv, m.twitch.tv at dashboard.twitch.tv, may 7TV, BTTV at FFZ man o wala
- **Nagsasalita rin ng mga wikang ito ang extension**: ang mga setting, popup at chat bar ay nasa 43 wika lahat, pili mula sa menu na may mga bandera
- **Libre agad pagka-install** gamit ang Google Translate. Magdagdag ng sarili mong libreng DeepL key para sa mas magandang salin sa mga wikang European;
  papalit ang MyMemory at Lingva kapag pumalya ang isang engine
- **On-device na pagsasalin** sa Chrome at Edge kapag inaalok ng browser: walang network, walang quota, at
  hindi umaalis sa computer mo ang teksto
- **Mga filter**: laktawan ang mga bot, i-mute ang mga user o channel, itago ang mga linyang may partikular na salita, isalin lang
  ang mga wikang pipiliin mo
- **Gawa para sa mabilis na chat**: ang mga pangalan ng emote mula sa 7TV, BTTV at FFZ set ng channel ay hindi kailanman isinasalin, kahit hindi mo gamit ang mga extension na iyon, isinasantabi ang mga link at @mention bago ipadala ang kahit ano, may glosaryo para sa mga pangalang nagugulo ng mga engine, at may translation cache
- **Apat na istilo ng display**: sa ilalim ng mensahe, sa parehong linya, kapalit ng mensahe, o kapag na-hover lang
- **I-pause ang isang channel** mula sa chat bar nang hindi hinihinto ang iba. Kapag lumipat ng channel o na-update ang
  extension, tuloy ang pagsasalin sa mga bukas na tab, hindi na kailangang mag-reload
- **May alam sa moderation**: ang mensaheng binura ng moderator, o inalis ng timeout o ban, nawawalan din ng salin
- **Kamukha ng Twitch**: purple, at sinusunod nito ang dark o light na theme ng mismong chat maliban kung pumili ka ng iba

## I-install

I-download ang zip para sa browser mo mula sa [Releases](https://github.com/kilworks/twitch-chat-translator/releases/latest) at i-unzip ito.

- Chrome, Brave, Edge (`…-chromium.zip`): buksan ang `chrome://extensions`, i-on ang Developer mode, i-click ang Load unpacked, piliin ang folder.
- Firefox 121+ (`…-firefox.zip`): buksan ang `about:debugging#/runtime/this-firefox`, i-click ang Load Temporary Add-on, piliin ang `manifest.json`.
  Nakakalimutan ng Firefox ang pansamantalang add-on kapag nag-restart ito.

Hindi kusang nag-a-update ang kopyang ininstall nang ganito: may badge sa icon nito kapag may mas bagong bersyon, at ang
popup ay may link papunta sa pinakabagong release.

## Mga translation engine

Apat na serbisyo, magkakadugtong: kapag pumalya ang isa, ang susunod ang papalit. Ikaw ang bahala sa pagkakasunod-sunod.

| Serbisyo | Key | Tala |
|---|---|---|
| Google | wala | ang default, gumagana agad |
| DeepL | libre | pinakamagaling sa mga wikang European, [libreng key](https://www.deepl.com/pro-api) para sa 1 milyong character kada buwan |
| MyMemory | wala | fallback |
| Lingva | wala | fallback, sa pampublikong instance maliban kung ituro mo sa sarili mong instance |

Ang built-in na translator ng Chromium ay hindi nangangailangan ng network at walang quota. Puwede itong ialok ng Chrome at Edge 138 pataas,
pero hindi lahat ng kopya ay mayroon, at ang bawat pares ng wika ay kailangang i-download nang isang beses ang model, isang click
lang mula sa bar. Wala nito ang Firefox. Kung saan man ito wala, ang cloud chain ang papalit at walang masisira.

## Mga setting

I-click ang gear sa chat bar, o i-right-click ang icon ng extension at piliin ang Mga opsyon.

- **Mga serbisyo**: pagkakasunod-sunod ng mga engine, ang DeepL key mo, at ang mode: on-device muna, cloud muna, o on-device lang
- **Hitsura**: wikang isasalin, istilo ng display, orihinal na teksto at badge ng wika, laki ng teksto, espasyo ng linya,
  font, accent color, theme ng chat, ang preview ng sinusulat at kung ano ang mangyayari kapag na-click ito
- **Mga filter**: mga bot, user, channel, keyword, orihinal na wika, at isang glosaryo ng mga kapalit
- **Mga advanced**: laki at tagal ng cache, sabay-sabay na request, rate limit kada channel, backup at pag-restore
- **Aktibidad**: mga naisalin na mensahe, cache hit, bawat wikang nakita sa chat, at kung bakit isinalin o hindi ginalaw ang bawat isa sa huling 50
  linya
- **Keyboard**: Alt+Shift+T para i-on o i-off ang pagsasalin ng chat (ang Alt+T ay theater mode ng Twitch), Alt+W para sa preview
  ng sinusulat. Puwedeng i-rebind ang dalawa sa mga shortcut ng extension ng browser mo
- Ang button ng wika sa action bar ng chat, sa ilalim ng message box: isang click para buksan ang listahan ng mga wikang
  sinusulatan mo, ang pag-type ay nagfi-filter nito. Ang nasa itaas ng chat ang nagtatakda ng wikang binabasa mo

## Privacy

Walang account, walang server ko, at walang analytics maliban kung mag-opt in ka sa araw-araw na hindi kilalang bilang na ipinadala sa Google Analytics (mga makinang ginamit, mga error, bilis, hindi kailanman ang iyong mga mensahe, pangalan o channel). Sa translation provider na pinili mo lang napupunta ang mga mensahe sa chat, at ang draft mo habang naka-on ang preview ng sinusulat,
at wala nang iba, at sa on-device mode ay hindi man lang doon. Para malaman ang wika ng channel, nagtatanong ito sa Twitch ng broadcast language at id ng channel, at para hindi maisalin ang mga pangalan ng emote, nagtatanong ito sa 7TV, BetterTTV at FrankerFaceZ ng mga pangalan ng emote ng channel, na nagsasabi lang sa kanila ng id ng channel at wala nang iba. Walang ibang request ang kopyang galing sa store. Ang
kopyang mano-manong ininstall ay nagtatanong sa GitHub ng pinakabagong release tag, hanggang isang beses kada anim na oras, para malaman kung
ipapakita ang update badge. [Mga detalye](PRIVACY.md)

## FAQ

**Hindi naisasalin ang mga mensahe.**
Buksan ang tab na Aktibidad sa mga setting at pindutin ang "Basahin ang mga desisyon": ililista nito ang huling 50 linya at sasabihin kung bakit
isinalin o hindi ginalaw ang bawat isa. Karamihan sa mga nilaktawan ay sinadya: iisang user na inuulit ang sarili, masyadong
maikling linya, emoji o tawa lang, o nasa wika mo na. Kung walang lumabas sa tab, ibig sabihin hindi nakikita ng extension
ang chat:
paki-open ng issue.

**Nawala ang purple na bar.**
I-refresh ang page. Kung maulit, magbukas ng [issue](https://github.com/kilworks/twitch-chat-translator/issues)
kasama ang channel at ang ginawa mo bago iyon.

**Paano makakakuha ng mas magandang salin?**
Magdagdag ng libreng DeepL key sa mga setting. Sakop ng libreng tier ang isang milyong character kada buwan, at ginagamit lang ang DeepL
sa mga pares ng wika kung saan mas magaling ito kaysa sa mga libreng engine.

**Anong istilo ng display ang dapat kong gamitin?**
Sa ilalim ng mensahe. Gumagana rin ang tatlo pa, pero inaayos pa ang mga ito.

**Magagamit ko ba ang extension sa wika ko?**
Oo. Sinusunod nito ang wika ng browser mo, at sa menu sa itaas ng mga setting puwede mo itong ilipat sa alinman sa
43.

**Gumagana ba ito sa 7TV, BTTV at FFZ?**
Oo, may alinman sa mga iyon o wala. Hindi isinasalin ang mga pangalan ng emote nila.

**Gumagana ba ito sa VOD at clip?**
Oo, kapareho ng sa mga live stream.

**Nasira ito pagkatapos ng update ng Twitch.**
Minsan binabago ng Twitch ang pagkakagawa ng chat nito. Magbukas ng [issue](https://github.com/kilworks/twitch-chat-translator/issues)
at aayusin ito.

**Gawa ba ito ng Twitch?**
Hindi. Independent na open-source na proyekto ito, walang kaugnayan sa Twitch.

## Ano ang bago

Sa 1.0.0, ang unang release para sa Twitch:

- Binabasa ang Twitch chat sa tatlong anyo nito: ang sariling listahan ng Twitch (pati may BTTV at FFZ), ang 7TV list, at VOD at clip replay, sa popout, embed, moderator view, stream manager at mobile
- Isinusulat ang mga salin sa message box na nananatiling salita ang mga emote, at hindi kailanman isinasalin ang mga pangalan ng emote mula sa 7TV, BTTV at FFZ set ng channel
- Mula sa Twitch ang wika ng channel, nawawalan ng salin ang binurang mensahe, at purple ang hitsura na sumusunod sa dark o light na chat ng Twitch
- Ang Alt+Shift+T ang nag-o-on o nag-o-off ng pagsasalin, isinisingit lang ng Tab ang salin kapag hindi katatapos ng 7TV o BTTV ng isang emote, at nasa action bar sa ilalim ng message box ang button ng wika

Lahat ng release, kasama ang nabago at ang pagsukat sa likod nito:
[Releases](https://github.com/kilworks/twitch-chat-translator/releases) at [CHANGELOG.md](CHANGELOG.md).

## Development

```bash
git clone https://github.com/kilworks/twitch-chat-translator.git
cd twitch-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
npm run package:all      # both zips, in release/
npm run dev              # HMR
```

Reproducible ang mga build: iisang commit ang magbibigay ng byte-identical na mga zip sa kahit anong makina, tinitiyak sa pamamagitan ng pag-build ng
`git archive` ng tag sa walang laman na folder at paghahambing ng mga hash.

Bukod sa mga unit test, mga offline gate ang naglo-load ng na-build na extension sa totoong browser, pinapatakbo ito at tinitiyak
ang ginagawa nito, na lokal ang serbisyo ng page at lokal ang sagot ng translation engine. Kailangan nila ng
Playwright, na sadyang hindi dependency: ituro ang `UX_KIT` sa folder na may `node_modules` nito,
o patakbuhin ang `npm i -D playwright`.

```bash
node test/e2e/run-gates.mjs --headless                  # all the offline gates, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

Nasa `src/shared/i18n/` ang mga string ng interface (popup at options, nakakey sa English na teksto) at
`src/content/i18n/` (chat bar, nakakey sa id na may English na teksto bilang fallback), isang file kada wika;
sinisigurado ng mga test na kumpleto ang key set ng bawat file. Nasa [store/](store/) ang mga
teksto ng store, at ang release ay isang version tag: bina-build, tinitiyak at pinapublish ito ng CI sa parehong
store.

Stack: Manifest V3, Vite, TypeScript, Preact, Tailwind.
