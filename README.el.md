# Twitch Chat Translator

Διάβασε το chat οποιουδήποτε stream στο Twitch στη δική σου γλώσσα και απάντησε στη γλώσσα του καναλιού.<br>
Δωρεάν, χωρίς λογαριασμό, χωρίς ρυθμίσεις. 43 γλώσσες, στο chat και στην ίδια την επέκταση.

## Πώς λειτουργεί

1. Εγκατέστησέ την και άνοιξε οποιοδήποτε stream στο Twitch. Μια μοβ μπάρα πάνω στο chat δείχνει ότι είναι
   ενεργή.
2. Κάθε μήνυμα παίρνει τη μετάφρασή του ακριβώς από κάτω μόλις φτάσει, στη γλώσσα του προγράμματος περιήγησής
   σου. Και στα ζωντανά stream, στα VOD και στα clip.
3. Γράψε μια απάντηση στη δική σου γλώσσα. Μια προεπισκόπηση πάνω από το πλαίσιο του chat τη δείχνει στη γλώσσα
   του καναλιού: πάτα Tab ή κάνε κλικ πάνω της και αυτή η εκδοχή αντικαθιστά ό,τι έγραψες.

Η γλώσσα του καναλιού είναι αυτή που όρισε ο streamer στο Twitch, οπότε δεν χρειάζεται να ρυθμίσεις τίποτα. Και οι δύο
γλώσσες αλλάζουν από τις ρυθμίσεις, και η γλώσσα ανάγνωσης μπορεί να απομνημονεύεται ξεχωριστά για κάθε κανάλι.

Αν χρησιμοποιείς και 7TV ή BTTV, χρησιμοποιούν κι αυτά το Tab για να ολοκληρώσουν ένα emote. Τότε το Tab ολοκληρώνει
πρώτα το emote και εισάγει τη μετάφραση μόνο όταν δεν είχε τίποτα να ολοκληρώσει. Το Ctrl/Cmd+Enter και ένα κλικ
την εισάγουν πάντα.

## Τι παίρνεις

- **43 γλώσσες**, και γλώσσες που γράφονται από δεξιά προς τα αριστερά (αραβικά, εβραϊκά, περσικά), με τις
  περιφερειακές παραλλαγές ξεχωριστές (βραζιλιάνικα και ευρωπαϊκά πορτογαλικά, απλοποιημένα και παραδοσιακά
  κινεζικά, καντονέζικα)
- **Παντού όπου υπάρχει chat**: ζωντανό chat, popout, embed, προβολή συντονιστή, ο διαχειριστής του stream,
  επανάληψη VOD και clip, στα www.twitch.tv, m.twitch.tv και dashboard.twitch.tv, με ή χωρίς 7TV, BTTV και FFZ
- **Η επέκταση τις μιλάει κι αυτή**: ρυθμίσεις, αναδυόμενο παράθυρο και μπάρα του chat και στις 43, με επιλογή
  από μενού με σημαίες
- **Δωρεάν από την πρώτη στιγμή** με το Google Translate. Πρόσθεσε το δικό σου δωρεάν κλειδί DeepL για καλύτερες
  ευρωπαϊκές γλώσσες· το MyMemory και το Lingva παίρνουν τη σκυτάλη όταν αποτυγχάνει μια μηχανή
- **Μετάφραση στη συσκευή** σε Chrome και Edge όπου την προσφέρει το πρόγραμμα περιήγησης: χωρίς δίκτυο, χωρίς όριο,
  και το κείμενο δεν φεύγει ποτέ από τον υπολογιστή σου
- **Φίλτρα**: παράλειψη bots, σίγαση χρηστών ή καναλιών, απόκρυψη γραμμών που περιέχουν μια λέξη, μετάφραση μόνο
  των γλωσσών που διαλέγεις
- **Φτιαγμένο για γρήγορα chat**: τα ονόματα των emotes από τα σετ 7TV, BTTV και FFZ του καναλιού δεν μεταφράζονται
  ποτέ, ακόμα κι αν δεν έχεις αυτές τις επεκτάσεις, οι σύνδεσμοι και τα @mentions παραμερίζονται πριν σταλεί
  οτιδήποτε, γλωσσάριο για ονόματα που οι μηχανές κατακρεουργούν, cache μεταφράσεων
- **Τέσσερα στυλ εμφάνισης**: κάτω από το μήνυμα, στην ίδια γραμμή, στη θέση του ή μόνο στο πέρασμα του δείκτη
- **Παύση ενός καναλιού** από τη μπάρα του chat χωρίς να σταματήσουν τα υπόλοιπα. Η αλλαγή καναλιού ή η
  ενημέρωση της επέκτασης αφήνει τις ανοιχτές καρτέλες να μεταφράζουν, χωρίς επαναφόρτωση
- **Σέβεται τη διαχείριση**: ένα μήνυμα που διαγράφει ο συντονιστής, ένα timeout ή ένα ban χάνει κι αυτό τη μετάφρασή του
- **Μοιάζει με το Twitch**: μοβ, και ακολουθεί το σκούρο ή ανοιχτό θέμα του ίδιου του chat, εκτός αν διαλέξεις εσύ

## Εγκατάσταση

Κατέβασε το zip για το πρόγραμμα περιήγησής σου από τα [Releases](https://github.com/kilworks/twitch-chat-translator/releases/latest) και αποσυμπίεσέ το.

- Chrome, Brave, Edge (`…-chromium.zip`): άνοιξε `chrome://extensions`, ενεργοποίησε τη λειτουργία προγραμματιστή, πάτα Load unpacked και διάλεξε τον φάκελο.
- Firefox 121+ (`…-firefox.zip`): άνοιξε `about:debugging#/runtime/this-firefox`, πάτα Load Temporary Add-on και διάλεξε το `manifest.json`.
  Το Firefox ξεχνά ένα προσωρινό πρόσθετο όταν επανεκκινεί.

Ένα αντίγραφο που εγκαθίσταται έτσι δεν ενημερώνεται μόνο του: το εικονίδιό του δείχνει σήμα όταν υπάρχει νεότερη
έκδοση και το αναδυόμενο παράθυρο παραπέμπει στην τελευταία έκδοση.

## Μηχανές μετάφρασης

Τέσσερις πάροχοι σε αλυσίδα: όταν αποτυγχάνει ένας, παίρνει τη σκυτάλη ο επόμενος. Τη σειρά την ορίζεις εσύ.

| Πάροχος | Κλειδί | Σημείωση |
|---|---|---|
| Google | κανένα | η προεπιλογή, δουλεύει αμέσως |
| DeepL | δωρεάν | η καλύτερη στις ευρωπαϊκές γλώσσες, [δωρεάν κλειδί](https://www.deepl.com/pro-api) για 1 εκατομμύριο χαρακτήρες τον μήνα |
| MyMemory | κανένα | εφεδρικός |
| Lingva | κανένα | εφεδρικός, σε δημόσιο διακομιστή εκτός αν δείξεις τον δικό σου |

Ο ενσωματωμένος μεταφραστής του Chromium δεν χρειάζεται δίκτυο ούτε όριο χρήσης. Το Chrome και το Edge 138 και
νεότερα μπορούν να τον προσφέρουν, αν και όχι κάθε αντίγραφο, και για κάθε ζεύγος γλωσσών το μοντέλο πρέπει να
κατεβεί μία φορά, με ένα κλικ από τη μπάρα. Το
Firefox δεν τον έχει. Όπου λείπει, η αλυσίδα cloud παίρνει τη σκυτάλη και τίποτα δεν χαλάει.

## Ρυθμίσεις

Κάνε κλικ στο γρανάζι της μπάρας του chat ή δεξί κλικ στο εικονίδιο της επέκτασης και διάλεξε «Επιλογές».

- **Πάροχοι**: σειρά μηχανών, το κλειδί DeepL και ο τρόπος: πρώτα στη συσκευή, πρώτα cloud ή μόνο στη συσκευή
- **Εμφάνιση**: γλώσσα προορισμού, στυλ εμφάνισης, αρχικό κείμενο και σήμα γλώσσας, μέγεθος κειμένου, διάστιχο,
  γραμματοσειρά, χρώμα έμφασης, θέμα συνομιλίας, η προεπισκόπηση μηνύματος και τι κάνει το κλικ πάνω της
- **Φίλτρα**: bots, χρήστες, κανάλια, λέξεις-κλειδιά, γλώσσες πηγής και ένα γλωσσάριο αντικαταστάσεων
- **Για προχωρημένους**: μέγεθος και διάρκεια ζωής της cache, ταυτόχρονα αιτήματα, όριο ρυθμού ανά κανάλι,
  αντίγραφο ασφαλείας και επαναφορά
- **Δραστηριότητα**: μεταφρασμένα μηνύματα, επιτυχίες cache, κάθε γλώσσα που εμφανίστηκε στο chat και γιατί
  καθεμία από τις τελευταίες 50 γραμμές μεταφράστηκε ή αφέθηκε ως έχει
- **Πληκτρολόγιο**: το Alt+Shift+T ενεργοποιεί ή απενεργοποιεί τη μετάφραση του chat (το Alt+T είναι η λειτουργία
  θεάτρου του Twitch), το Alt+W την προεπισκόπηση μηνύματος. Και τα δύο αλλάζουν από τις συντομεύσεις επεκτάσεων
  του προγράμματος περιήγησής σου
- Το κουμπί γλώσσας στη γραμμή ενεργειών του chat, κάτω από το πλαίσιο μηνύματος: ένα κλικ ανοίγει τη λίστα των
  γλωσσών στις οποίες γράφεις και η πληκτρολόγηση τη φιλτράρει. Αυτό στην κορυφή του chat ορίζει τη γλώσσα στην
  οποία διαβάζεις

## Απόρρητο

Κανένας λογαριασμός, κανένας διακομιστής μου και κανένα αναλυτικό στοιχείο, εκτός και αν επιλέξετε να συμμετέχετε σε έναν καθημερινό ανώνυμο αριθμό που αποστέλλεται στο Google Analytics (κινητήρες που χρησιμοποιούνται, σφάλματα, ταχύτητα, ποτέ τα μηνύματα, τα ονόματα ή τα κανάλια σας). Τα μηνύματα του chat, και το πρόχειρό σου όσο είναι ενεργή η προεπισκόπηση μηνύματος, πηγαίνουν στον πάροχο
μετάφρασης που διάλεξες και πουθενά αλλού, και στη λειτουργία στη συσκευή ούτε εκεί. Για να μάθει τη γλώσσα του
καναλιού ρωτά το Twitch για τη γλώσσα μετάδοσης και το id του καναλιού, και για να κρατά τα ονόματα των emotes
εκτός μεταφράσεων ρωτά το 7TV, το BetterTTV και το FrankerFaceZ για τα ονόματα των emotes του καναλιού, κάτι που
τους λέει το id του καναλιού και τίποτα άλλο. Ένα αντίγραφο από store δεν κάνει κανένα άλλο αίτημα. Ένα αντίγραφο
που εγκαταστάθηκε χειροκίνητα ρωτά το GitHub για το tag της τελευταίας έκδοσης, το πολύ κάθε έξι ώρες, για να ξέρει
αν θα δείξει το σήμα ενημέρωσης. [Λεπτομέρειες](PRIVACY.md)

## Συχνές ερωτήσεις

**Τα μηνύματα δεν μεταφράζονται.**
Άνοιξε την καρτέλα Δραστηριότητα στις ρυθμίσεις και πάτα «Ανάγνωση αποφάσεων»: δείχνει τις τελευταίες 50
γραμμές και γιατί καθεμία μεταφράστηκε ή αφέθηκε ως έχει. Οι περισσότερες γραμμές που παραλείπονται παραλείπονται επίτηδες: ο ίδιος χρήστης που επαναλαμβάνεται, πολύ σύντομες
γραμμές, μόνο emoji ή γέλια, ή γραμμές που είναι ήδη στη γλώσσα ανάγνωσης. Αν η καρτέλα δεν δείχνει
τίποτα, η επέκταση δεν βλέπει το chat: άνοιξε ένα issue.

**Η μοβ μπάρα εξαφανίστηκε.**
Ανανέωσε τη σελίδα. Αν ξανασυμβεί, άνοιξε ένα [issue](https://github.com/kilworks/twitch-chat-translator/issues)
με το κανάλι και τι έκανες πριν.

**Πώς παίρνω καλύτερες μεταφράσεις;**
Πρόσθεσε ένα δωρεάν κλειδί DeepL στις ρυθμίσεις. Το δωρεάν πλάνο καλύπτει ένα εκατομμύριο χαρακτήρες τον μήνα και
το DeepL ξοδεύεται μόνο στα ζεύγη γλωσσών όπου κερδίζει τις δωρεάν μηχανές.

**Ποιο στυλ εμφάνισης να διαλέξω;**
Κάτω από το μήνυμα. Τα άλλα τρία δουλεύουν, αλλά ακόμη βελτιώνονται.

**Μπορώ να χρησιμοποιήσω την επέκταση στη γλώσσα μου;**
Ναι. Ακολουθεί τη γλώσσα του προγράμματος περιήγησής σου και το μενού στην κορυφή των ρυθμίσεων την αλλάζει σε
οποιαδήποτε από τις 43.

**Δουλεύει με 7TV, BTTV και FFZ;**
Ναι, με οποιοδήποτε από αυτά ή με κανένα. Τα ονόματα των emotes τους μένουν εκτός των μεταφράσεων.

**Δουλεύει στα VOD και στα clip;**
Ναι, με τον ίδιο τρόπο όπως στα ζωντανά stream.

**Χάλασε μετά από ενημέρωση του Twitch.**
Το Twitch αλλάζει κατά καιρούς τον τρόπο που είναι χτισμένο το chat του. Άνοιξε ένα [issue](https://github.com/kilworks/twitch-chat-translator/issues)
και θα διορθωθεί.

**Το φτιάχνει το Twitch;**
Όχι. Είναι ανεξάρτητο έργο ανοιχτού κώδικα, χωρίς σχέση με το Twitch.

## Τι νέο υπάρχει

Στην 1.0.0, την πρώτη έκδοση για το Twitch:

- Διαβάζει το chat του Twitch στις τρεις μορφές του: τη δική του λίστα του Twitch (και με BTTV και FFZ), τη λίστα του 7TV, και την επανάληψη VOD και clip, σε popout, embed, προβολή συντονιστή, στον διαχειριστή του stream και στο κινητό
- Γράφει τις μεταφράσεις στο πλαίσιο μηνύματος με τα emotes ως λέξεις, και δεν μεταφράζει ποτέ τα ονόματα των emotes από τα σετ 7TV, BTTV και FFZ του καναλιού
- Η γλώσσα του καναλιού έρχεται από το Twitch, ένα διαγραμμένο μήνυμα χάνει τη μετάφρασή του, και η εμφάνιση είναι μοβ και ακολουθεί το σκούρο ή ανοιχτό chat του Twitch
- Το Alt+Shift+T ενεργοποιεί ή απενεργοποιεί τη μετάφραση, το Tab εισάγει τη μετάφραση μόνο όταν το 7TV ή το BTTV δεν μόλις ολοκλήρωσαν ένα emote, και το κουμπί γλώσσας βρίσκεται στη γραμμή ενεργειών κάτω από το πλαίσιο μηνύματος

Κάθε έκδοση, με ό,τι άλλαξε και τη μέτρηση πίσω από αυτό:
[Releases](https://github.com/kilworks/twitch-chat-translator/releases) και [CHANGELOG.md](CHANGELOG.md).

## Ανάπτυξη

```bash
git clone https://github.com/kilworks/twitch-chat-translator.git
cd twitch-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
npm run package:all      # both zips, in release/
npm run dev              # HMR
```

Τα builds είναι αναπαραγώγιμα: το ίδιο commit δίνει zip πανομοιότυπα byte προς byte σε οποιοδήποτε μηχάνημα, κάτι
που ελέγχεται χτίζοντας ένα `git archive` του tag σε κενό φάκελο και συγκρίνοντας τα hashes.

Πέρα από τα unit tests, οι offline έλεγχοι φορτώνουν την έτοιμη επέκταση σε πραγματικό πρόγραμμα περιήγησης, την
οδηγούν και επιβεβαιώνουν τι κάνει, με τη σελίδα να σερβίρεται τοπικά και τη μηχανή μετάφρασης να απαντά τοπικά.
Χρειάζονται το Playwright, που εσκεμμένα δεν είναι εξάρτηση: δείξε το `UX_KIT` σε φάκελο του οποίου το
`node_modules` το περιέχει, ή τρέξε `npm i -D playwright`.

```bash
node test/e2e/run-gates.mjs --headless                  # all the offline gates, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

Τα κείμενα της διεπαφής βρίσκονται στο `src/shared/i18n/` (αναδυόμενο παράθυρο και ρυθμίσεις, με κλειδί το
αγγλικό κείμενο) και στο `src/content/i18n/` (μπάρα του chat, με κλειδί το id και το αγγλικό κείμενο ως
εφεδρικό), ένα αρχείο ανά γλώσσα· τα tests απαιτούν από κάθε αρχείο το πλήρες σύνολο κλειδιών. Τα κείμενα για τα
store βρίσκονται στο [store/](store/) και μια έκδοση είναι ένα tag έκδοσης: το CI τη χτίζει, την ελέγχει και τη
δημοσιεύει και στα δύο store.

Στοίβα: Manifest V3, Vite, TypeScript, Preact, Tailwind.
